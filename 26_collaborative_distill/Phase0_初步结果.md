# Phase 0 初步结果：双教授（dsv4pro + doubao）并集与错误重叠

> 2026-08-18 | 数据口径：测试集 8293 题（medqa 1273 + medmcqa 4183 + mmlu 2837）
> 标签进度：dsv4pro 8201/8293（官方 DeepSeek key）；doubao 5172/8293（方舟，剩 3121 题欠费待补）；glm52 暂停。
> 本结果用"两者都答过"的交集 5126 题计算（偏 medqa+medmcqa，缺 mmlu，故个体准确率比 ~90% 基准略低）。

## 一、数字

| 指标 | 数值 |
|---|---|
| dsv4pro 个体准确率 | 86.89% |
| doubao 个体准确率 | 86.09% |
| 并集准确率（至少一个对） | **90.71%** |
| 最强单模型（dsv4pro） | 86.89% |
| **并集增益** | **+3.82pp** |
| 错误重叠（dsv4pro 错时 doubao 也错） | **70.8%（互补 29.2%）** |

## 二、对 P1/P2 的验证结论

- **P1（三强并集 > 95%）——未达到**。实际双教授并集 90.71%，增益 +3.82pp。即使补上 glm52（第三个 ~90% 教授）并集也难到 95%（三个强模型错误重叠高，第三个能补的很有限）。
- **P2（错误重叠 < 50%）——证伪**。实际错误重叠 **70.8%**，比我预判的 <50% 高，甚至比三弱模型里 flash→qwen3 的 66.8% 还高。

## 三、关键洞察（大白话）

1. **强模型之间互补是真实存在的，但比我预期的小**：+3.82pp 并集增益、29% 错误互补——"两个大教授"确实有对方不会的题，值得 brainstorm，但盘子比三弱模型的 +6.84pp 小。
2. **为什么强模型错误重叠更高（70% vs 三弱的 67%）**：强模型只在"最难的题"上犯错，而那些题是大家都难的，所以一个错另一个也大概率错。反直觉但合理——"越强越容易一起错"。
3. **这正好印证老师那句"要看情况"**：并集上限（+3.82pp）= 那杯"浑水里的有机物"，真实存在但不多；能不能靠"辩论/仲裁"把它从 90.71% 抓成真实准确率（而不是简单投票抓不住），就是 Phase 1-2 要答的核心问题。
4. **并集增益是"可抓取上限"**：简单投票在分歧题上≈随机，只能抓 ~1-2pp；要抓到接近 +3.82pp 需要"辩论/仲裁"能在分歧题上判断"谁是对的"。这正是老师说的"几个大教授 brainstorm 才有机会出好 idea"——机会的量级就是这 +3.82pp。

## 四、下一步

1. 方舟续费后补完 doubao 剩 3121 题（全量 8293 口径）。
2. 全量数字算完后，进入 Phase 1-2：在训练集上做"教授辩论/仲裁"机制，验证能不能把 +3.82pp 并集上限兑现成真实准确率。
3. 提醒：强模型并集增益只有 ~3.8pp，且重叠 70%——如果辩论/仲裁抓不到多少，就诚实收口（技术期刊的"绝对提升"门槛会很难够，走 conference/dental 更稳）。
