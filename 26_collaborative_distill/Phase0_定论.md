# Phase 0 定论：双教授（dsv4pro + doubao）并集与错误重叠

> 2026-08-18 | 数据口径：测试集 8293 题（medqa 1273 + medmcqa 4183 + mmlu 2837）
> 标签进度：dsv4pro 8201/8293；doubao 8284/8293；glm52 暂停（方舟限速，全量不现实）。
> 本结果用"两者都答过"的交集 **8194 题**（≈99% 覆盖）计算。

## 一、最终数字

| 指标 | 数值 |
|---|---|
| dsv4pro 个体准确率 | 88.60% |
| doubao 个体准确率 | 87.83% |
| 并集准确率（至少一个对） | **91.68%** |
| 最强单模型（dsv4pro） | 88.60% |
| **并集增益** | **+3.08pp** |
| 错误重叠（dsv4pro 错时 doubao 也错） | **73.0%（互补 27.0%）** |

（初步 5126 题子集口径：并集 90.71%、增益 +3.82pp、重叠 70.8%。全量后重叠略升、增益略降，结论一致。）

## 二、对 P1/P2 的验证结论（定论）

- **P1（并集 > 95%）——证伪**。双教授并集 91.68%，增益只有 +3.08pp。补上 glm52（同为 ~88% 强模型，且错误高度重叠）也到不了 95%。
- **P2（错误重叠 < 50%）——证伪**。实际错误重叠 **73.0%**，比预判的 <50% 高得多，也比三弱模型（flash→qwen3 66.8%、flash→llama 39.4%）高。

## 三、关键洞察（大白话）

1. **强模型互补真实存在但很小**：并集 91.68% 比最强单模型高 3.08pp；dsv4pro 错的 934 题里，有 27%（252 题）doubao 能答对——这就是"可抓取的互补"。
2. **强模型错误高度重叠（73%）**：因为强模型只在"最难的题"上犯错，而那些题大家都难。**"越强越容易一起错"**——这是反直觉但最重要的发现。
3. **并集增益 +3.08pp 就是"那杯浑水里的有机物"**：真实存在、但量级只有 ~3pp，且 73% 的错误是"谁都错"（共识错误），真正可互补的只有 27% 的错误。
4. **对"辩论/仲裁"的预期要下调**：能抓的上限就是 +3.08pp（完美仲裁），简单投票只能抓 ~1pp（分歧题≈随机）。即使辩论机制完美，最终学生也只能从 ~88.6% 提到 ~91.7%。
5. **这印证老师"要看情况"**：强教授的并集上限(+3.08pp)远小于三弱模型的 +6.84pp——**强模型不是靠"互相补错"变强，是靠"本来就强"**。"群体智能蒸馏"的价值上限，在"强教授"组合下只有 ~3pp，而不是 6.84pp。

## 四、对后续实验的影响（重要判断）

1. **技术期刊的"绝对提升"门槛很难够**：我们的协作蒸馏最多能比"单老师蒸馏"多 +3pp（甚至更少，因为单老师蒸馏本身也有 ~+4pp 增益，而协作蒸馏是把"并集答案"当标签，标签上限就是 91.68%）。要"打赢所有 SOTA 蒸馏方法 + 绝对提升"非常难。
2. **更现实的路径**：
   - 把"强模型错误重叠 73%"+"并集增益只有 3pp"本身写成**经验发现**（conference 或技术期刊的经验/分析型论文），比硬造"方法创新"更稳。
   - 或转向"弱-强混合协作"（弱模型互补大 +6.84pp 但抓不住，强模型互补小 +3pp 但可能抓得住）——但这是新的研究问题。
3. **glm52 建议不再全量补**：两个 ~88% 强模型的结论已经稳定，第三个强模型只会让重叠更高、并集增益更小，且方舟对它限速，性价比极低。

## 五、下一步（等你定夺）

- 方案 A：进入 Phase 1-2，在训练集上做"教授辩论/仲裁"，实测能不能把 +3.08pp 并集上限兑现（预期兑现有限）。
- 方案 B：把 Phase 0 的发现（强模型互补只有 3pp、错误重叠 73%）作为经验结论收口，写 conference/dental 论文。
- 方案 C：重新审视"协作蒸馏"的目标——也许该用"弱-强混合"或"多弱模型"来放大互补，而不是"三个强教授"。
