# gating/置信度路由实验：能否抓住 Llama 带来的 +2pp

> 2026-08-18 | 交集 8194 题。Llama 置信度用 vLLM 存的 TeacherEntropy（熵）。
> 先验证了 Llama 熵是良好校准信号：熵<0.2 时 79.7% 正确、熵>1.0 时仅 18%。

## 一、结果

| 策略 | 准确率 |
|---|---|
| 最强单模型 dsv4pro（基线） | 88.60% |
| 并集（理论上限，oracle） | 93.68% |
| 规则A：熵阈值路由（Llama 高置信+分歧则改信 Llama）θ<0.05 | 81.10% |
| 规则A θ<0.2 | 79.40% |
| 规则A θ<1.2 | 75.60% |
| 规则B：强教师一致→用，分歧→Llama，再叠 Llama 高置信覆盖 | 同规则A，全跌 |
| 规则C：强教师一致→用，分歧→直接用 Llama | 88.21% |

## 二、结论（决定性负面结果）

**置信度路由不仅抓不住 +2pp，反而全面下跌。** 关键机制：

- Llama 的置信度在"全局"上是校准的（低熵→79.7% 正确），但在"相对强教师"上不校准：
  - "强教师对 + Llama 自信地错 + 分歧"的题（~10%）：路由到 Llama 会**改错**；
  - "强教师错 + Llama 自信地对 + 分歧"的题（~1-2%，就是那 +2pp）：路由到 Llama 能**改对**。
  - 前者是后者的 ~5-10 倍，所以任何阈值下路由都净亏。

- 规则C（仅分歧题用 Llama）也只有 88.21%，略低于基线 88.60%——因为强教师分歧的题是难题，Llama 在上面只有 ~50% 准头。

## 三、对论文/洞见的意义

1. **"智能路由能抓住 +2pp"被证伪**（至少在"弱模型置信度"这一信号下）。弱模型的互补知识，因为它的"自信错"远多于"自信对且强模型错"，无法被置信度路由兑现。
2. 这比"投票抓不住"更强：**即使有校准良好的置信度信号，也抓不住**。要抓住那 +2pp，需要一个"知道强模型什么时候错"的信号，而置信度/一致性都提供不了——这本质上又回到"知识不足"：没有额外知识，就无法判断谁对。
3. 再次坐实老师洞见：**协作/路由/投票都无法凭空产生知识；真正的杠杆是新语料**。

## 四、下一步建议

- gating 这条（用 Llama 置信度）已收口为负面结果，不必再深挖（除非换"强教师自身置信度/自一致性"信号，但预期同样有限，因为共识错误的根源是知识盲点）。
- 论文里可加一句："并集上限 +5pp（三模型）中，投票实现 0、置信度路由实现负收益——互补需要模型之外的新知识才能兑现。"
