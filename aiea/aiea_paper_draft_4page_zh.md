## 题目

用于高效牙科选择题自动答题的 Choice-Head 蒸馏方法

## 摘要

大语言模型在医学问答基准上已经表现出较强能力，但它们的部署成本仍然较高。这个问题在标准化牙科选择题任务中尤其明显，因为这类任务的输出空间很小、结构很明确，但传统蒸馏方法仍然通常依赖完整词表上的监督。本文提出 Choice-Head distillation，这是一种与任务结构对齐的蒸馏框架，它只蒸馏五个答案选项 A、B、C、D、E 上的概率分布。这样的设计减少了计算冗余，支持黑盒 API 教师，并让学习目标直接对齐下游决策空间。实验在基于 CMExam 构建的全量数据和牙科子集上进行，教师模型为 DeepSeek-V3，学生模型为 Qwen2.5-7B 和 Qwen2.5-14B。在 991 题的全量测试集上，最佳 14B 学生模型达到 89.10% 准确率，超过了 87.18% 的教师模型，同时更容易部署。结果表明，对于结构化医学选择题任务，决策空间蒸馏是一种有效而且实用的替代方案，可以替代传统的词表级监督。

## 关键词

知识蒸馏，医学问答，大语言模型，选择题推理，决策空间监督

## 1. 引言

医学大语言模型在职业考试类基准上已经取得较强结果，包括中文医学执业考试相关数据集。但高基准分数并不自动意味着模型适合实际部署。在教育辅助、考试训练和轻量级决策支持这类场景中，推理成本和结果可复现性与模型精度同样重要。

本文关注牙科选择题自动答题任务。每道题都只有五个候选答案。尽管输出空间天然受限，很多大语言模型蒸馏方法仍然围绕全词表 logits 或自由生成目标进行训练。这会带来不必要的冗余，而且对于黑盒 API 教师来说也不方便，因为内部 logits 往往无法访问。

为了解决这种任务结构与监督目标之间的不匹配，本文不再围绕通用语言建模空间设计蒸馏，而是直接围绕任务决策结构进行重构。我们提出 Choice-Head distillation，即只迁移教师在 A、B、C、D、E 五个答案选项上的分布。

本文有两个核心贡献。第一，我们为五选一医学选择题提出了一个与任务结构对齐的蒸馏框架。第二，我们证明了在这种设定下，较小的学生模型可以超过更强的教师模型。具体来说，由 DeepSeek-V3 蒸馏得到的 Qwen2.5-14B 学生模型在 991 题 CMExam 测试集上达到 89.10%，高于教师模型的 87.18%。

## 2. 相关工作

知识蒸馏的目标是把大模型的知识迁移到更小的学生模型中，常见方式包括软标签蒸馏、中间表示蒸馏以及特定任务监督。在大语言模型领域，蒸馏已经被扩展到词表级 logits、推理链生成以及多种工程化压缩工具。对于医学大语言模型，已有工作通常更关注更强教师和更大数据集，而较少讨论监督目标本身是否应该随着任务结构而改变。

本文方法与通用大语言模型蒸馏的区别在于，我们把答案选项分布视为主要迁移对象，而不是完整词表输出。这样做使得整个框架更轻量，更兼容黑盒教师，也更适合标准化选择题任务。

## 3. 方法

### 3.1 问题定义

给定一道五选一选择题 $x$，目标是预测正确答案 $y \in \{A, B, C, D, E\}$。记 $p_T$ 为教师模型在五个选项上的分布，记 $p_S$ 为学生模型在同一组选项上的分布。

传统蒸馏是在完整 token 词表上最小化分布差异。与此不同，本文只蒸馏与最终决策直接相关的选项分布。

### 3.2 Choice-Head 蒸馏

第一阶段训练同时使用蒸馏监督和真实标签监督，其损失函数为：

$$
L = \alpha D_{KL}(p_T \parallel p_S) + (1-\alpha)L_{CE}.
$$

在本文主设置中，$\alpha = 0.35$。相对于词表级蒸馏，这种做法有三个优点。第一，它与任务本身更对齐。第二，它在计算上更高效。第三，它天然兼容黑盒教师，因为它不要求访问完整词表 logits 或内部隐状态。

图 2 可以用于展示带有选项级教师监督的 Choice-Head 蒸馏训练流程。

### 3.3 训练策略

在整个项目中，我们还探索过一个两阶段训练策略，即在第一阶段之后，再加第二阶段的真实标签监督微调。但大规模实验表明，对于较强的 14B 学生模型来说，第二阶段并不是必须的，甚至可能带来轻微负面影响。因此，本文最终采用的最佳 14B 配置只使用第一阶段训练。

## 4. 实验设置

本文使用一个基于 CMExam 重构的数据划分。该数据由 6591 道单选医学题组成，覆盖七个学科。训练集、验证集和测试集的规模分别为 4608、991 和 991。与此同时，我们还保留了一个牙科子集用于专业方向评测。

主教师模型是 DeepSeek-V3，它在 991 题测试集上的准确率为 87.18%。学生模型包括 Qwen2.5-7B-Instruct 和 Qwen2.5-14B-Instruct。训练采用 LoRA，rank 为 16，LoRA alpha 为 32。对于本文的主 14B 配置，我们使用一个 Stage 1 epoch，学习率为 $1 \times 10^{-4}$。

## 5. 结果与讨论

表 1 汇报了在 CMExam 全量测试集和牙科测试集上的主要结果。

| 模型 | 设置 | 全量测试准确率 | 牙科测试准确率 |
| --- | --- | ---: | ---: |
| Qwen2.5-7B | 零样本基线 | 76.49% | 68.80% |
| Qwen2.5-14B | 零样本基线 | 83.55% | 74.40% |
| DeepSeek-V3 | 教师模型 | 87.18% | 79.20% |
| Qwen2.5-7B | Choice-Head Stage 1 平均 | 85.60% | 73.60% |
| Qwen2.5-14B | Choice-Head Stage 1 平均 | 88.67% | 79.20% |
| Qwen2.5-14B | Choice-Head Stage 1 最佳 | 89.10% | 78.40% |

结果显示，该方法对两种学生模型都有明显增益。7B 学生模型相比自己的全量测试零样本基线提升了 9.11 个百分点；14B 学生模型平均提升了 5.12 个百分点。更关键的是，最佳 14B 学生模型达到 89.10%，超过了 87.18% 的教师模型。

图 3 可以用于对比 14B 零样本基线、教师模型以及蒸馏后 14B 学生模型的表现。

这个学生超过教师的结果并不意味着蒸馏失败。恰恰相反，它说明当蒸馏目标与任务结构对齐时，学生模型可以把教师提供的软标签信息和任务本身的优化目标结合起来，从而学到更强的任务决策边界。

另一个重要发现是，第二阶段训练并不总是有益。对于更强的学生模型和更大的训练集，额外的真实标签微调可能会覆盖掉原本有价值的软标签结构，而不是进一步提升效果。在本文设定中，更简单的 Stage 1-only 配置反而是表现最好的版本。

本文方法之所以有效，是因为它去除了与任务无关的监督维度，保留了五个答案选项之间最重要的不确定性结构，并且让强大的 API 教师真正能够参与训练流程。

## 6. 结论

本文提出了用于牙科选择题自动答题的 Choice-Head distillation 方法。通过只蒸馏五个答案选项上的分布，而不是完整词表输出，该方法让监督目标与任务结构保持一致，同时兼容黑盒教师。在 991 题的 CMExam 测试集上，最佳 14B 学生模型达到 89.10%，超过了 87.18% 的 DeepSeek-V3 教师模型。结果说明，对于结构化医学选择题任务，决策空间蒸馏是一条切实可行的高效部署路径。
