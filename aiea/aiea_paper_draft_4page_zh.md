## 题目

用于牙科选择题自动答题的 Choice-Head 蒸馏方法

## 摘要

医学大语言模型在考试基准上得分很高，但部署成本仍然很高。这个问题在牙科选择题任务中尤其明显，因为任务输出只有五个选项，但很多蒸馏方法仍然对整个词表做监督。本文提出 Choice-Head distillation，只迁移教师在答案选项上的分布。这个方法与任务结构对齐，计算开销低于词表级蒸馏，并且兼容黑盒 API 教师。实验使用基于 CMExam 的重分割数据，教师为 DeepSeek-V3，学生为 Qwen2.5-7B 和 Qwen2.5-14B。在 991 题的全量测试集上，最佳 14B 学生达到 89.10%，超过 87.18% 的教师模型。结果说明，对于结构化医学选择题任务，决策空间蒸馏是一条切实可行的小模型部署路径。

## 关键词

知识蒸馏，医学问答，大语言模型，选择题推理，决策空间监督

## 1. 引言

知识蒸馏的基本目标，是把大模型的软标签迁移到更小的学生模型中。近年的医疗和通用大语言模型进一步强化了这个问题的重要性，因为高分往往伴随高推理成本，而真实部署更需要小模型而不是最大的教师模型。

本文研究牙科选择题自动答题，这是一个标准的五选一决策任务。任务结构很简单，但很多蒸馏方案仍然使用全词表 logits 或自由生成目标。对于固定选项任务来说，这样的监督目标是冗余的；对于 API 黑盒教师来说，也不方便获取。

为了解决这种不匹配，本文提出 Choice-Head distillation。它不再迁移完整词表输出，而是只迁移教师在五个答案选项上的分布。

本文有两个核心贡献。第一，提出一个面向五选一医学选择题的任务对齐蒸馏目标。第二，证明这种设定可以得到超过教师模型的学生模型。具体来说，由 DeepSeek-V3 蒸馏得到的 Qwen2.5-14B 学生模型在 991 题 CMExam 测试集上达到 89.10%，高于教师模型的 87.18%。

## 2. 相关工作

经典知识蒸馏把教师的软化目标分布迁移给学生模型。后续研究又把这一思路扩展到紧凑 Transformer、参数高效微调和工程化压缩工具中。在语言模型领域，最常见的迁移目标仍然是完整词表分布。

在医学问答任务中，已有工作更多关注更强的教师和更大的评测集，而较少讨论一个更基础的问题：如果下游任务本身是固定选项考试，监督目标是不是也应该跟着任务结构改变。本文的不同点正在这里。我们迁移的是答案选项分布，而不是完整词表输出。

## 3. 方法

### 3.1 问题定义

给定一道五选一选择题 $x$，目标是预测正确答案 $y \in \{A, B, C, D, E\}$。记 $p_T$ 为教师模型在五个选项上的分布，记 $p_S$ 为学生模型在同一组选项上的分布。

传统蒸馏是在完整 token 词表上最小化分布差异。与此不同，本文只蒸馏与最终决策直接相关的选项分布。

### 3.2 Choice-Head 蒸馏

第一阶段训练同时使用蒸馏监督和真实标签监督，其损失函数为：

$$
L = \alpha D_{KL}(p_T \parallel p_S) + (1-\alpha)L_{CE}.
$$

在本文主设置中，$\alpha = 0.35$。相对于词表级蒸馏，这种做法有三个优点。第一，它与任务本身更对齐。第二，它在计算上更高效。第三，它天然兼容黑盒教师，因为它不要求访问完整词表 logits 或内部隐状态。

公式（1）就是本文第一阶段的核心训练目标。

图 2 可以用于展示带有选项级教师监督的 Choice-Head 蒸馏训练流程。

### 3.3 训练策略

在整个项目中，我们还探索过一个两阶段训练策略，即在第一阶段之后，再加第二阶段的真实标签监督微调。但大规模实验表明，对于较强的 14B 学生模型来说，第二阶段并不是必须的，甚至可能带来轻微负面影响。因此，本文最终采用的最佳 14B 配置只使用第一阶段训练。

## 4. 实验设置

本文使用基于 CMExam 的重分割数据，共 6591 道单选医学题，覆盖七个学科。训练集、验证集和测试集分别为 4608、991 和 991。另保留一个 125 题牙科子集，用于补充性专业评测。

教师模型是 DeepSeek-V3。学生模型是 Qwen2.5-7B-Instruct 和 Qwen2.5-14B-Instruct。训练使用 LoRA，rank 为 16，LoRA alpha 为 32。本文主 14B 配置只运行一轮 Stage 1，学习率为 $1 \times 10^{-4}$。

## 5. 结果与讨论

表 1 汇报了在 CMExam 全量测试集和牙科测试集上的主要结果。

| 模型 | 设置 | 全量测试准确率 | 牙科测试准确率 |
| --- | --- | ---: | ---: |
| Qwen2.5-7B | 零样本基线 | 76.49% | 68.80% |
| Qwen2.5-14B | 零样本基线 | 83.55% | 74.40% |
| DeepSeek-V3 | 教师模型 | 87.18% | 79.20% |
| Qwen2.5-7B | Choice-Head Stage 1 平均 | 85.60% | 73.60% |
| Qwen2.5-14B | Choice-Head Stage 1 平均 | 88.67% | 79.20% |
| Qwen2.5-14B | Choice-Head Stage 1 最佳 | 89.10% | 78.40% |

结果显示，该方法对两种学生模型都有明显增益。在全量测试集上，7B 学生从 76.49% 提升到 85.60%，提高了 9.11 个百分点；14B 学生从 83.55% 提升到 88.67%，平均提高了 5.12 个百分点。最佳 14B 结果达到 89.10%，超过了 87.18% 的教师模型。

图 3 可以用于对比 14B 零样本基线、教师模型以及蒸馏后 14B 学生模型的表现。

这张表最应该关注的是 991 题全量测试集，而不是更小的牙科子集。牙科子集仍然有价值，但题量更小，因此更容易波动。在主测试集上，蒸馏后的 14B 学生同时超过了自己的零样本基线和教师模型。

学生超过教师并不意味着蒸馏失败。相反，这说明当蒸馏目标和任务结构对齐时，学生模型可以把教师的不确定性信息与任务本身的优化目标结合起来，从而形成更强的决策边界。

另一个重要发现是，第二阶段训练并不总是有益。对于更强的学生模型和更大的训练集，额外的真实标签微调可能会覆盖掉原本有价值的软标签结构，而不是进一步提升效果。在本文设定中，更简单的 Stage 1-only 配置反而是表现最好的版本。

本文方法之所以有效，是因为它去除了与任务无关的监督维度，保留了五个答案选项之间最重要的不确定性结构，并且让强大的 API 教师真正能够参与训练流程。

## 6. 结论

本文提出了用于牙科选择题自动答题的 Choice-Head distillation 方法。该方法只蒸馏五个答案选项上的分布，而不是完整词表输出，因此让监督目标更接近任务本身，同时兼容黑盒教师。在 991 题 CMExam 测试集上，最佳 14B 学生模型达到 89.10%，超过了 87.18% 的 DeepSeek-V3 教师模型。结果说明，对于结构化医学选择题任务，决策空间蒸馏是一条切实可行的小模型部署路径。
