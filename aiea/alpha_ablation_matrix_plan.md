# Choice-Head 蒸馏 α 消融：三组合矩阵实验规划

> 论文：*Choice-Head Distillation for Dental MCQA* (AIEA) 的消融扩展
> 目的：把"α=0(纯CE)最优"从单一组合(14B+DeepSeek)的观察，升级为跨教师质量、跨学生容量的有理论支撑的规律。
> 状态：组合①已完成；组合②③规划+脚本搭建中，排进流水线自动跑。

---

## 0. 一句话

**用三个(教师×学生)组合做同一个 α 消融，验证"最优 α 趋于0、教师软标签(KL)增量有限甚至有害"是否随教师质量/学生容量稳健移动。
三组合的教师-金标准不一致率差异巨大(12.2% vs 48.4%)，构成天然的"教师质量"因果梯度——这是本消融最有说服力的设计。**

## 1. 三组合矩阵

| 组合 | 教师 | 学生 | 教师-金标准不一致率 | 状态 |
|---|---|---|---|---|
| ① | DeepSeek-V3 | Qwen2.5-**14B** | **12.2%** | ✅已完成(见 alpha_ablation_results.md) |
| ② | DeepSeek-V3 | Qwen2.5-**7B** | 12.2% | ⏳排队(验证学生容量维度) |
| ③ | **Llama-3.3-70B** | Qwen2.5-14B | **48.4%** | ⏳排队(验证教师质量维度) |

- ① vs ②：固定教师，变学生容量 → 检验"弱学生是否更需要软标签(最优α右移)"。
- ① vs ③：固定学生，变教师质量 → 检验"差教师(48%错)是否让KL更有害(α=0更强最优)"。
- 三点共同勾勒：最优α如何随两个关键变量移动。

## 2. 已完成组合①的结果(锚点)

14B + DeepSeek-V3，7α×3seed，内置eval val均值：
- α=0: 89.61% ⬅最优 → α=0.35: 88.60% → α=1.0(纯KL): 86.21%
- val随KL权重单调下降；α=0 比 α=0.35 高+1.01pp，比纯KL高+3.40pp。
- canonical eval(对齐论文Table I)：α=0 full **89.14%** > 主结果88.67% > 教师87.18% > 基线83.55%；dental 82.13%(125题方差大)。
- 结论：KL非性能主因、轻微有害；超越教师靠决策空间监督(Choice-Head)，非dark knowledge蒸馏。

## 3. 理论预测(消融前 git 冻结，供事后检验)

α最优值由三个量决定，本矩阵系统性地动其中两个：

### 维度A：教师-金标准不一致率
KL与CE只在教师与金标准"打架"的样本上分歧。
- 不一致率低(DeepSeek 12.2%)：KL能加的信息少，且分歧里教师未必对 → α偏0。
- 不一致率高(Llama 48.4%)：教师近一半在"教错"，KL把错误答案的概率质量也蒸给学生 → **KL更有害，α=0应更强烈最优，KL惩罚曲线更陡**。
→ **预测：组合③的 α=1.0 性能崩塌比组合①更严重；α=0 优势更大。**

### 维度B：学生容量
- 强学生(14B)：能自己拟合金标准，不需软标签平滑 → α偏0(组合①已证)。module13也证Stage-2对14B有害，同理。
- 弱学生(7B)：可能更受益于软标签的正则化 → **最优α可能右移(>0)**。
→ **预测：组合② 7B 的最优α 可能比14B 略大，或平台区更宽。若7B也α=0最优，则"α=0稳健"结论更强。**

### 维度C：任务类别数(本矩阵不变，5选1)
5个类→软标签的"类间关系"信息天然贫乏→KL价值受限。这是三组合共享的结构前提，也是Choice-Head定位(小决策空间)的根基。

---

## 4. 判定标准(同组合①，第4节口径)

记最优α的canonical full均值 Acc*，α=0为Acc0，3seed std≈0.3-0.5pp，阈值1.0pp。
对每个组合：
- 若 Acc*≥教师 且 Acc*−Acc0<1pp → KL可有可无(情景B，KL非主因)。
- 若 α=0就是最优 → KL有害(比B更强)。
- 跨组合看趋势：不一致率越高，α=0优势应越大(维度A因果)。

## 6. 小论文产出结构(交给老师)

建议结构(IEEE/技术报告)：
1. **动机**：单组合消融不足以支撑"KL有限"的一般性结论，需跨教师质量×学生容量验证。
2. **方法**：三组合矩阵，唯一变量α，其余冻结；canonical统一评估；判定标准预注册。
3. **结果**：三条α-准确率曲线 + 一张矩阵总表(每组合最优α、α=0 vs 最优、KL惩罚斜率)。
4. **分析**：用不一致率(12.2% vs 48.4%)解释跨教师差异；用容量解释跨学生差异。
5. **结论**：在"小决策空间+低教师噪声"下KL增量有限/有害，收益来自决策空间监督(Choice-Head)；外推边界诚实声明(类别数增大/教师接近金标准时可能不同)。
6. **诚实附录**：所有负结果、小样本(dental125、Llama2223子集)方差、单一数据集等边界。
