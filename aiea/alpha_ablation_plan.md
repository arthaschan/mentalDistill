# Choice-Head KL 蒸馏 α 消融实验方案

> 论文：*Choice-Head Distillation for Dental Multiple-Choice Question Answering* (AIEA)
> 目的：用消融实验确定 Stage-1 损失中 **α**（KL 权重）的最优值，并检验论文核心结论是否仍然成立。
> 状态：方案 + 可运行脚本已就绪，等待算力空闲后启动（单 H100，与另一会话排队）。

---

## 0. 一句话结论（先读这个）

α 控制「教师软标签(KL) vs 金标准答案(CE)」的配比：`Loss_stage1 = α·KL + (1−α)·CE`。
论文主设置 α=0.35（即 CE 权重 0.65）。本消融要回答**两个问题**：

1. **最优 α 是多少？** —— 在 0.0~1.0 之间扫一条曲线，按验证集选点。
2. **「Choice-Head 蒸馏」叙事是否成立？** —— 关键看 **α=0（纯 CE / 等价于在选项空间做 SFT，完全不用教师）** 是否显著差于最优混合 α。
   - 若 α=0 明显更差 → 教师 KL 的「dark knowledge」确实有贡献，论文「蒸馏」叙事成立。
   - 若 α=0 与最优点打平（在统计噪声内）→ 教师信号其实可有可无，论文应诚实改写为「选项空间监督」而非「知识蒸馏」。

这是本实验对论文最有杀伤力、也最该提前想清楚的一点。

---

## 1. 背景：α 到底是什么

Stage-1 的损失（见 `shared/train_choice_head_distill.py:170-212`）：

```
Loss = α · KL(teacher_dist ‖ student_dist) + (1 − α) · CE(student, gold_answer)
```

- KL、CE 都只在 5 个选项 token（A/B/C/D/E）的 logits 上计算（这正是 "Choice-Head" 的含义）。
- α=0.35 → KL 权重 0.35，CE 权重 0.65（与论文正文 "CE term carries a weight of 0.65" 一致）。
- 教师 DeepSeek-V3 与金标准在训练集上有 **12.2% 不一致**，所以 KL 和 CE 在这 12.2% 上会「拉扯」，α 决定拉扯的方向。
- 脚本已原生支持 `--alpha`，**消融无需改任何训练代码**，只改这一个数。

### α 的两个端点（物理含义）

| α | 含义 | 预期 |
|---|------|------|
| **0.0** | 纯 CE，完全不用教师 = 在选项空间对金标准做 SFT | **关键对照**：检验教师是否「真的有用」 |
| 0.35 | 论文主设置（已训完，可复用 s11/s42/s8） | 88.67% 均值（基准锚点） |
| **1.0** | 纯 KL，完全模仿教师（含其 12.2% 的错误） | **关键对照**：应被教师准确率 ~87% 封顶或更低 |

## 2. 实验设计

### 2.1 主网格（14B，论文头条模型）

| 维度 | 取值 |
|------|------|
| α (扫描) | **0.0, 0.15, 0.25, 0.35, 0.50, 0.65, 1.0**（7 点） |
| 学生 | Qwen2.5-14B-Instruct |
| 种子 | **11, 42, 8**（与 module 15 主实验完全一致，保证可比） |
| 阶段 | 仅 Stage-1（与主实验一致；module 13 已证 Stage-2 对 14B 有害） |
| 其余超参 | **全部冻结**：lr=1e-4, r=16, lora_alpha=32, bs=2, grad_accum=4, epoch=1, deterministic |

- **总训练量**：7 点 × 3 种子 = 21 次；其中 α=0.35 的 3 次**已存在**（module 15），实际只需新训 **6 点 × 3 种子 = 18 次**。
- **唯一变量是 α**，其它一切照搬主实验 → 干净的单因素消融。

### 2.2 可选扩展（7B，稳健性）

若时间允许，在 Qwen2.5-7B 上重复同一网格（7B 单次更快），用于验证「最优 α 是否随模型容量变化」。7B 主实验用种子 11/42/7、两阶段；为单因素干净起见，消融**只跑 Stage-1**，与 14B 对齐。这是 nice-to-have，不是核心交付。

## 3. 评估与选点准则（避免在测试集上挑数）

1. **曲线评估**：所有 α 点全程使用**同一套** prompt（即 `train_choice_head_distill.py` 内置的 `evaluate_generation`），保证 α 之间内部可比。
2. **选点**：在**验证集 val.jsonl（991 题）** 上按 3 种子均值选最优 α —— **绝不**用测试集选点（防止 cherry-pick）。
3. **头条对齐**：选出的最优 α，其 3 个种子再用 **canonical 评估**（`scripts/run_eval_dual.py` → `shared/evaluate_model.py`，full 991 + dental 125）重跑一次，才能和论文 Table I 的 87.18% 教师、各基线、88.67% 主结果**在同一 prompt 下**直接比较。

> ⚠️ 方法学坑（已验证）：训练内置 eval 的 prompt（"只需输出一个字母"）与 canonical eval 的 prompt（"请根据你的专业知识…"）不同，同一 adapter 在两者下准确率不同（实测 s8：内置 eval test=87.59% vs canonical=89.10%）。因此曲线和头条数字**不能混用两套 prompt**——曲线全用内置、头条全用 canonical，分开陈述。

## 4. 「核心结论是否成立」的明确判定标准（提前 git 冻结）

记最优 α 在 canonical full-test 上的 3 种子均值为 `Acc*`，α=0 的为 `Acc0`，教师=87.18%，14B 零样本基线=83.55%。3 种子 std ≈ 0.35pp，991 题 95% CI ≈ ±2.5pp，因此判定阈值取 **≥1.0pp** 为「实质差异」（约 2–3× 种子 std）。

**核心结论 = 「Choice-Head 蒸馏让 14B 学生匹配/超越教师」**，判定如下：

- ✅ **完全成立**：`Acc* ≥ 87.18%`（≥教师）**且** `Acc* − Acc0 ≥ 1.0pp`（教师 KL 有实质增量）。
- ⚠️ **部分成立（需改写叙事）**：`Acc* ≥ 87.18%` 但 `Acc* − Acc0 < 1.0pp`。
  → 「超越教师」成立，但「靠蒸馏」不成立；真正起作用的是「选项空间 SFT」。论文须把卖点从"知识蒸馏"调整为"决策空间监督"，并把 α=0 作为诚实对照写进去。
- ❌ **不成立**：`Acc* < 87.18%`。→ 任何 α 都没超过教师，头条结论被推翻（基于已有 88.67% 结果，这种概率很低）。

另外检验 α=1.0：预期 `Acc(α=1) ≲ 87%`（被教师上限封顶），用于佐证「纯模仿教师不如混合金标准」。

## 4.5 结论稳健性分级 —— 「我原本的结论会不会塌」的正面回答

> 这一节专门回应核心担忧：**哪些结论消融动不了，哪些只是换说法，没有任何情景会让论文「白做」。**

### 先分清两层结论

| 层级 | 具体陈述 | 消融能否动摇 |
|------|---------|-------------|
| **L1 事实层（铁的）** | 14B 蒸馏 3 种子均值 **88.67%**、最佳 **89.10%**，**> 教师 87.18%**；7B 从 76.49%→85.60% | **动不了**。这些数字来自已完成、已落盘的 module 15 run。α 消融是**新增**别的 α 的实验，不会回写、不会删除这些已测结果。 |
| **L2 归因层（要验证的）** | 这个超越「**靠的是教师软标签蒸馏（KL）**」 | **会被检验**。风险只在这一层。 |
| **L3 定位层（最稳的卖点）** | 「在**5 选 1 决策空间**而非全词表上做监督，更轻量、兼容黑盒 API 教师、可部署」 | **动不了**，且与 α 取值无关——无论最优 α 是多少，监督都发生在 5 个选项 token 上，这正是 "Choice-Head" 的定义。 |

**关键认识**：你论文标题和方法的核心是 **L3（决策空间监督）**，不是 L2（蒸馏归因）。L3 完全不依赖消融结果。所以最坏情况下要修的是 L2 的措辞，L1 和 L3 纹丝不动。

### 三种情景，论文各自保住什么（没有「全盘不成立」这一项）

**情景 A —— KL 实质有用（Acc* ≥ 教师 且 Acc*−Acc0 ≥ 1pp）**
- 结论：全部三层都成立，且多了一张干净的消融曲线坐实 α=0.35 附近最优。
- 论文动作：加一节消融 + 一张曲线图，叙事不变。**这是最强结局。**

**情景 B —— KL 与纯 SFT 打平（Acc* ≥ 教师 但 增量 < 1pp）** ← 我判断概率最高
- L1 仍成立（学生确实超过教师）、L3 仍成立（决策空间监督依然轻量好部署）。
- 唯一要改：把"知识蒸馏的 dark knowledge 是超越教师的主因"这句**收回**，改成诚实表述：
  > "在 5 选 1 任务上，教师软标签带来的增量有限（消融显示 α∈[0,0.5] 性能平坦）；**真正的收益来自把监督对齐到决策空间**。这与任务只有 5 个类、教师-金标准仅 12.2% 不一致的事实一致。"
- **这不是退步，是加分**：主动报告"KL 没那么神"+ 给出机制解释（12.2% 不一致 + 5 类任务），正是严谨审稿人想看到的诚实消融。比"假装 KL 很关键但被审稿人一句话戳穿"安全得多。
- 论文卖点重心从"蒸馏"平移到"决策空间监督 + 黑盒兼容 + 可部署"，标题和方法名 Choice-Head 都不用改。

**情景 C —— 任何 α 都打不过教师（Acc* < 87.18%）**
- 这要求新训的所有 α 点连同已存在的 0.35 列一起"退化"，但 0.35 列已实测 88.67%——**除非复现性出问题，否则不可能发生**。
- 真要发生，第一步是排查环境漂移（torch/transformers 版本、模型权重），而不是接受结论翻盘。

### 一句话给你吃定心丸

> 你最担心的"结论不成立"= 情景 C，而 C 几乎要求已落盘的 88.67% 自我推翻，概率极低。
> 现实里最可能落在 A 或 B，**两者论文都活，区别只是「蒸馏是主角」还是「决策空间监督是主角」**。
> 而决策空间监督本来就是你方法名 Choice-Head 的本意——所以无论 A 还是 B，你的核心定位都稳。

## 5. 诚实的预期与风险（不粉饰）

1. **曲线很可能在 α≈0.2~0.5 一段是平的**：14B 种子 std 仅 0.35pp，若最优区间内各点差异 <1pp，正确结论是「α 在一个**宽区间**内都最优，0.35 是其中之一而非唯一最优」，而**不是**「0.35 精确最优」。要按这个口径写，别过度解读小数点。
2. **α=0 打平的真实风险**：选项空间里只有 5 个类、金标准本身质量高，纯 CE（SFT）很可能已经很强。一旦 α=0 ≈ 最优点，这是对论文最大的质疑点——但提前做了这个对照，反而把它变成论文的「诚实加分项」而非审稿人的「致命一击」。
3. **教师-金标准不一致仅 12.2%**：KL 与 CE 的分歧只发生在这 1/8 样本上，所以 α 的影响天然被稀释，曲线平坦是可预期的，不代表实验失败。
4. **单一教师 / 单一学生族**：本消融不改变论文 Limitations 里已声明的这条边界。
