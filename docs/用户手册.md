# mentalDistill 用户手册

## 1. 程序用途

mentalDistill 是一个基于 CMExam 医学选择题数据的知识蒸馏实验平台，用于研究如何把高性能教师模型的医学选择题答题能力迁移到更小、可部署的学生模型。

本平台主要支持以下任务：

- 基线训练：直接使用标准答案对学生模型做监督微调。
- 知识蒸馏：使用本地模型或 API 教师生成软标签，再训练 7B / 14B 学生模型。
- 教师评测：评估 DeepSeek、Doubao、Qwen、Llama 等教师在医学选择题上的表现。
- 数据集构造：构建蒸馏训练集、全量重分割数据集、多教师融合数据集。
- 模型评估：统一评估训练后的模型准确率。
- 可视化与演示：提供模型推理 Web 界面和人机答题 Web 界面。
- 论文辅助：提供论文导出、答辩 PPT 生成、论文格式检查相关工具。

## 2. 适用对象

本手册适用于以下用户：

- 需要复现实验结果的教师或评审人员
- 需要继续维护代码仓库的开发者
- 需要运行训练、评估或 Web 演示的学生用户
- 需要检查论文 Word 文档格式的作者本人

## 3. 程序结构说明

仓库采用“模块化实验 + 共享脚本”的结构：

- 00_baseline_gt_sft 至 20_adaptive_alpha：各独立实验模块
- shared：共享训练、评估、标签生成、Web 服务脚本
- scripts：全局数据重分割等辅助脚本
- docs：实验报告、分析文档与提交材料
- thesis：论文、答辩材料与论文导出脚本
- 根目录：环境检查、批量运行、论文 Word 检查工具

## 4. 运行环境

### 4.1 软件环境

推荐环境如下：

- 操作系统：Linux（推荐 Ubuntu）
- Python：3.10 及以上，仓库当前使用 Anaconda Python 3.13
- 深度学习框架：PyTorch 2.0 及以上
- Transformers：4.51.0 及以上
- PEFT：0.7.0 及以上
- Accelerate：0.20.0 及以上
- 其他依赖：datasets、requests、tqdm、numpy
- 可选依赖：vLLM、python-pptx、volcenginesdkcore

### 4.2 硬件环境

推荐 GPU 环境：

- 7B LoRA 训练：约 20GB 显存
- 14B LoRA 训练：约 35GB 显存
- 32B 白盒蒸馏：约 90GB 显存
- Llama-70B-AWQ 推理：约 38GB 显存

推荐设备：NVIDIA H100 NVL 95GB 或 A100 80GB。

## 5. 环境部署方法

### 5.1 克隆项目

```bash
git clone <repo-url> mentalDistill
cd mentalDistill
```

### 5.2 安装依赖

```bash
pip install -r requirements.txt
```

### 5.3 配置环境变量

复制示例环境配置：

```bash
cp setup.example.env setup.env
```

然后编辑 [setup.example.env](setup.example.env) 对应内容，重点配置：

- EASYEDIT_PY：Python 解释器路径
- MODELS_DIR：模型根目录
- BASE_MODEL_7B：Qwen2.5-7B-Instruct 路径
- BASE_MODEL_14B：Qwen2.5-14B-Instruct 路径
- BASE_MODEL_32B：Qwen2.5-32B-Instruct 路径
- BASE_MODEL_QWEN3_8B：Qwen3-14B / Qwen3-8B 路径
- DEEPSEEK_API_KEY：DeepSeek API Key
- DOUBAO_API_KEY：豆包 API Key
- MOONSHOT_API_KEY：Kimi API Key

### 5.4 下载模型

常用模型下载示例：

```bash
huggingface-cli download Qwen/Qwen2.5-7B-Instruct --local-dir models/Qwen2.5-7B-Instruct
huggingface-cli download Qwen/Qwen2.5-14B-Instruct --local-dir models/Qwen2.5-14B-Instruct
huggingface-cli download Qwen/Qwen2.5-32B-Instruct --local-dir models/Qwen2.5-32B-Instruct
huggingface-cli download Qwen/Qwen3-14B --local-dir models/Qwen3-14B
huggingface-cli download casperhansen/llama-3.3-70b-instruct-awq --local-dir models/Llama-3.3-70B-Instruct-AWQ
```

### 5.5 环境自检

```bash
source setup.env
bash check_env.sh
```

如果显示 Python 路径和模型路径正常，即表示环境部署成功。

## 6. 程序启动方法

### 6.1 运行单个实验模块

每个模块都统一提供脚本入口，最常用方法如下：

```bash
source setup.env

# 运行完整流程：教师标签 -> 训练 -> 评估
bash 02_deepseek_v3_choice_head/scripts/run_pipeline.sh

# 只训练
bash 02_deepseek_v3_choice_head/scripts/run_train.sh

# 只评估
bash 02_deepseek_v3_choice_head/scripts/run_eval.sh

# 启动模型推理 Web 页面
bash 02_deepseek_v3_choice_head/scripts/start_web.sh

# 启动人机答题页面
bash 02_deepseek_v3_choice_head/scripts/start_quiz.sh
```

### 6.2 批量运行多个模块

```bash
# 查看可用模块
bash run_module_batch.sh list

# 批量评估
bash run_module_batch.sh eval 00_baseline_gt_sft 02_deepseek_v3_choice_head

# 批量完整运行
bash run_module_batch.sh pipeline 00_baseline_gt_sft 02_deepseek_v3_choice_head
```

### 6.3 夜间 API 任务调度

```bash
bash run_night_api_tasks.sh
```

适用于批量生成教师 API 标签。

## 7. 程序调用方法

### 7.1 推荐调用方式

对于普通用户，推荐优先调用每个模块的 shell 入口脚本，而不是直接调用底层 Python 脚本。原因如下：

- shell 脚本已封装环境变量
- shell 脚本已约定输入输出路径
- 更适合论文复现和批量运行

### 7.2 直接调用核心 Python 脚本

#### 7.2.1 模型评估

```bash
python shared/evaluate_model.py \
  --base_model models/Qwen2.5-7B-Instruct \
  --adapter_dir 02_deepseek_v3_choice_head/outputs/best \
  --test_data 02_deepseek_v3_choice_head/data/test.jsonl \
  --wrong_log logs/test_wrong.jsonl
```

#### 7.2.2 启动答题 Web 页面

```bash
python shared/quiz_app.py \
  --test_data 00_baseline_gt_sft/data/test.jsonl \
  --host 0.0.0.0 \
  --port 7870 \
  --title "医学选择题测试"
```

启动后浏览器访问：http://0.0.0.0:7870

#### 7.2.3 启动模型推理 Web 页面

```bash
python shared/serve_model_app.py \
  --base_model models/Qwen2.5-7B-Instruct \
  --adapter_dir 02_deepseek_v3_choice_head/outputs/best \
  --host 127.0.0.1 \
  --port 7860 \
  --title "Dental Model App"
```

#### 7.2.4 生成 API 教师标签

```bash
python shared/generate_teacher_labels_api.py \
  --dataset 02_deepseek_v3_choice_head/data/train.jsonl \
  --candidate shared/teacher_candidate.sample.json \
  --system_prompt shared/system_prompt_mcq.txt \
  --output 02_deepseek_v3_choice_head/data/teacher_train.jsonl \
  --resume
```

## 9. 推荐使用流程

建议新用户按以下顺序使用：

1. 安装依赖并配置 [setup.example.env](setup.example.env)
2. 执行 `source setup.env && bash check_env.sh`
3. 先运行 Module 00 验证基线流程
4. 再运行 Module 02 复现最佳 7B 蒸馏方案
5. 如需更强学生模型，再运行 Module 13 或 Module 15
6. 如需 Web 演示，再执行 `start_web.sh` 或 `start_quiz.sh`
7. 如需论文提交辅助，再使用 thesis 目录下文档与 check 工具

## 10. 常见问题

### 10.1 为什么程序启动失败？

常见原因：

- 未执行 `source setup.env`
- 模型路径配置错误
- API Key 未设置
- GPU 显存不足
- Python 依赖未完整安装

### 10.2 为什么推荐用 shell 脚本而不是直接运行训练 Python 文件？

因为 shell 脚本已经封装了路径、环境变量和输出目录，复现实验更稳定，也更符合论文提交要求。

### 10.3 哪些内容不会包含在仓库中？

以下内容通常不会提交：

- 模型权重目录 `models/`
- 训练输出 `outputs/`、`runs/`
- 教师标签 `teacher_*.jsonl`
- 本地环境配置 `setup.env`
- 各类日志目录
