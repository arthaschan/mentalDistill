# mentalDistill 用户手册

## 1. 系统简介

mentalDistill 是一个面向医学选择题知识蒸馏研究的实验平台，基于 CMExam 医学考试题数据，围绕“教师模型到学生模型的能力迁移”组织实验。当前工作区保留 00 到 20 共 21 个实验模块，覆盖 GT SFT 基线、Choice-Head 蒸馏、白盒蒸馏、多教师融合、自蒸馏、推理链蒸馏、全量数据扩展以及信息几何分析。

本提交版手册只说明当前工作区中仍然存在且可随代码仓提交的文件，不包含已删除文件、本地临时检查脚本和其他被忽略内容。

当前仓库的数据使用约定如下：统一以 [shared/cmexam_full.csv](shared/cmexam_full.csv) 作为本地总表输入，再由重分割脚本生成训练集、验证集、测试集和牙科子集。结合当前代码与上游 CMExam 数据目录可核实，本仓库不直接读取上游的 train.csv、val.csv；若需回溯原始来源，应对应上游的 test_with_annotations.csv 整理结果。

## 2. 系统组成

仓库当前由以下部分组成：

1. 实验模块目录：00_baseline_gt_sft 至 20_adaptive_alpha。
2. shared 目录：训练、评估、教师标签生成、数据构造、分析和 Web 服务脚本。
3. scripts 目录：数据重分割脚本。
4. docs 目录：实验分析文档与本手册。
5. thesis 目录：论文提交源文件、参考材料与图表生成脚本。
6. 根目录入口：环境检查、批量执行和 README 汇总脚本。

## 3. 程序运行环境

### 3.1 软件环境

推荐运行环境如下：

- 操作系统：Linux，推荐 Ubuntu
- Python：3.10 及以上
- PyTorch：2.0.0 及以上
- Transformers：4.51.0 及以上
- PEFT：0.7.0 及以上
- Accelerate：0.20.0 及以上
- 其他基础依赖：datasets、numpy、requests、tqdm
- 可选依赖：vLLM、python-pptx、volcenginesdkcore

### 3.2 硬件环境

推荐硬件条件如下：

- 7B LoRA 训练：约 20GB 显存
- 14B LoRA 训练：约 35GB 显存
- 32B 白盒蒸馏：约 90GB 显存
- Llama-70B-AWQ 推理：约 38GB 显存

推荐使用 NVIDIA H100 NVL 95GB 或 A100 80GB GPU。

## 4. 环境部署方法

### 4.1 获取源码

```bash
git clone <repo-url> mentalDistill
cd mentalDistill
```

### 4.2 安装依赖

```bash
pip install -r requirements.txt
```

### 4.3 配置环境变量

```bash
cp setup.example.env setup.env
```

然后编辑 setup.env，建议至少配置以下内容：

- EASYEDIT_PY：Python 解释器路径
- MODELS_DIR：模型目录根路径
- BASE_MODEL_7B：Qwen2.5-7B-Instruct 路径
- BASE_MODEL_14B：Qwen2.5-14B-Instruct 路径
- BASE_MODEL_32B：Qwen2.5-32B-Instruct 路径
- BASE_MODEL_QWEN3_8B：Qwen3-14B 路径
- LLAMA70B_MODEL：Llama-3.3-70B-Instruct-AWQ 路径
- DEEPSEEK_API_KEY：DeepSeek API Key
- DOUBAO_API_KEY：豆包 API Key
- MOONSHOT_API_KEY：Kimi API Key

### 4.4 环境自检

```bash
source setup.env
bash check_env.sh
```

若系统能正确输出 Python 路径和模型路径，说明环境部署成功。

## 5. 程序启动方式

### 5.1 根目录入口

根目录当前保留的主要入口文件如下：

- check_env.sh：环境自检。
- run_module_batch.sh：批量运行模块。
- run_night_api_tasks.sh：夜间 API 任务调度。
- run_all_readme.sh：汇总查看各模块 README。

### 5.2 单个模块启动

不同模块保留的脚本并不完全相同，建议优先查看各模块 scripts 目录。当前常见入口包括：

```bash
source setup.env

bash 02_deepseek_v3_choice_head/scripts/run_pipeline.sh
bash 02_deepseek_v3_choice_head/scripts/run_train.sh
bash 02_deepseek_v3_choice_head/scripts/run_eval.sh
bash 02_deepseek_v3_choice_head/scripts/start_best_web.sh
bash 02_deepseek_v3_choice_head/scripts/start_quiz.sh
```

较常见的模块脚本类型如下：

1. 标准训练模块：run_teacher_eval.sh、run_train.sh、run_eval.sh、run_pipeline.sh、start_web.sh、start_best_web.sh、start_quiz.sh。
2. 数据准备脚本：build_head_dataset.sh、generate_teacher_labels.sh、prepare_soft_labels.sh。
3. 特殊模块脚本：
15_fulldata_resplit/scripts/run_train_7b.sh、run_train_14b.sh、run_eval_dual.py。
16_llama70b_choice_head/scripts/run_train_14b.sh、run_eval_dual.py。
17_alpha_divergence、19_boundary_filter、20_adaptive_alpha 当前仅保留 run_train.sh 为核心训练入口。
18_fisher_rao_analysis 当前保留 run_analysis.sh。

### 5.3 批量运行多个实验模块

```bash
bash run_module_batch.sh list
bash run_module_batch.sh eval 00_baseline_gt_sft 02_deepseek_v3_choice_head
bash run_module_batch.sh pipeline 00_baseline_gt_sft 02_deepseek_v3_choice_head
bash run_module_batch.sh teacher-eval 01_qwen32b_whitebox 05_qwen14b_choice_head
```

### 5.4 夜间 API 任务

```bash
bash run_night_api_tasks.sh
```

该脚本用于夜间批量调度 API 教师标签生成任务。

## 6. 程序调用方式

对于普通用户，建议优先使用模块目录下的 shell 脚本，而不是直接调用底层 Python 文件，原因如下：

1. shell 脚本已封装环境变量和目录路径。
2. shell 脚本已按实验约定组织输入输出。
3. 更便于复现实验与批量运行。

常用 Python 脚本直接调用示例如下。

### 6.1 模型评估

```bash
python shared/evaluate_model.py \
  --base_model models/Qwen2.5-7B-Instruct \
  --adapter_dir 02_deepseek_v3_choice_head/outputs/best \
  --test_data 02_deepseek_v3_choice_head/data/test.jsonl \
  --wrong_log logs/test_wrong.jsonl
```

### 6.2 启动人机答题界面

```bash
python shared/quiz_app.py \
  --test_data 00_baseline_gt_sft/data/test.jsonl \
  --host 0.0.0.0 \
  --port 7870 \
  --title "医学选择题测试"
```

### 6.3 启动模型推理界面

```bash
python shared/serve_model_app.py \
  --base_model models/Qwen2.5-7B-Instruct \
  --adapter_dir 02_deepseek_v3_choice_head/outputs/best \
  --host 127.0.0.1 \
  --port 7860 \
  --title "Dental Model App"
```

### 6.4 生成 API 教师标签

```bash
python shared/generate_teacher_labels_api.py \
  --dataset 02_deepseek_v3_choice_head/data/train.jsonl \
  --candidate shared/teacher_candidate.sample.json \
  --system_prompt shared/system_prompt_mcq.txt \
  --output 02_deepseek_v3_choice_head/data/teacher_train.jsonl \
  --resume
```

## 9. 推荐使用流程

建议首次使用本系统时，按以下顺序操作：

1. 安装依赖并配置 setup.env。
2. 执行 source setup.env 和 bash check_env.sh。
3. 先运行 Module 00 作为环境验证。
4. 再运行 Module 02 复现代表性的 7B 蒸馏方案。
5. 如需更高统计可靠性，继续运行 Module 15。
6. 如需跨架构蒸馏对比，运行 Module 16。
7. 如需查看实验材料，再参考 docs 和 thesis 目录当前保留文档。
