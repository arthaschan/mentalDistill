# mentalDistill 用户手册

## 1. 系统简介

mentalDistill 是一个面向医学选择题知识蒸馏研究的实验平台。系统基于 CMExam 医学考试题数据，围绕“教师模型到学生模型的能力迁移”这一目标，支持多种实验路线，包括基线监督微调、Choice-Head 两阶段蒸馏、白盒蒸馏、多教师融合、自蒸馏、推理链蒸馏、全量数据扩展、信息几何分析等。

本系统的主要用途包括：

1. 训练 7B 或 14B 学生模型，使其在牙科医学五选一选择题任务上获得较高准确率。
2. 调用 API 教师或本地教师，为训练集生成软标签或推理链数据。
3. 统一评估教师模型和学生模型在测试集上的表现。
4. 提供 Web 演示界面，支持模型问答展示和人工答题测试。
5. 为论文撰写、答辩展示和 Word 文档格式核查提供辅助工具。

## 2. 系统组成

系统由以下几部分组成：

1. 实验模块目录：00_baseline_gt_sft 至 20_adaptive_alpha。每个目录对应一类独立实验。
2. 共享脚本目录 shared：集中存放训练、评估、标签生成、数据构造和 Web 服务脚本。
3. 全局脚本目录 scripts：存放数据重分割等通用辅助程序。
4. 文档目录 docs：存放实验报告、分析文档和本用户手册。
5. 论文目录 thesis：存放论文、答辩材料和论文导出工具。
6. 根目录工具：存放环境自检脚本、批量调度脚本和论文格式检查脚本。

## 3. 程序运行环境

### 3.1 软件环境

推荐运行环境如下：

- 操作系统：Linux，推荐 Ubuntu
- Python：3.10 及以上
- PyTorch：2.0.0 及以上
- Transformers：4.51.0 及以上
- PEFT：0.7.0 及以上
- Accelerate：0.20.0 及以上
- 其他基础依赖：datasets、numpy、requests、tqdm
- 可选依赖：vLLM、python-pptx、volcenginesdkcore

### 3.2 硬件环境

推荐硬件条件如下：

- 7B LoRA 训练：约 20GB 显存
- 14B LoRA 训练：约 35GB 显存
- 32B 白盒蒸馏：约 90GB 显存
- Llama-70B-AWQ 推理：约 38GB 显存

推荐使用 NVIDIA H100 NVL 95GB 或 A100 80GB GPU。

## 4. 环境部署方法

### 4.1 获取源码

在目标机器上克隆项目：

```bash
git clone <repo-url> mentalDistill
cd mentalDistill
```

### 4.2 安装依赖

```bash
pip install -r requirements.txt
```

### 4.3 配置环境变量

复制环境变量模板文件：

```bash
cp setup.example.env setup.env
```

然后编辑 setup.env，至少需要配置以下内容：

- EASYEDIT_PY：Python 解释器路径
- MODELS_DIR：模型目录根路径
- BASE_MODEL_7B：Qwen2.5-7B-Instruct 路径
- BASE_MODEL_14B：Qwen2.5-14B-Instruct 路径
- BASE_MODEL_32B：Qwen2.5-32B-Instruct 路径
- BASE_MODEL_QWEN3_8B：Qwen3 模型路径
- DEEPSEEK_API_KEY：DeepSeek API Key
- DOUBAO_API_KEY：豆包 API Key
- MOONSHOT_API_KEY：Kimi API Key

### 4.4 下载模型

常用模型下载示例如下：

```bash
huggingface-cli download Qwen/Qwen2.5-7B-Instruct --local-dir models/Qwen2.5-7B-Instruct
huggingface-cli download Qwen/Qwen2.5-14B-Instruct --local-dir models/Qwen2.5-14B-Instruct
huggingface-cli download Qwen/Qwen2.5-32B-Instruct --local-dir models/Qwen2.5-32B-Instruct
huggingface-cli download Qwen/Qwen3-14B --local-dir models/Qwen3-14B
huggingface-cli download casperhansen/llama-3.3-70b-instruct-awq --local-dir models/Llama-3.3-70B-Instruct-AWQ
```

### 4.5 环境自检

执行以下命令：

```bash
source setup.env
bash check_env.sh
```

若系统正确输出 Python 路径和模型路径，说明环境部署成功。

## 5. 程序启动方式

### 5.1 运行单个实验模块

每个实验模块都提供统一 shell 启动脚本，推荐调用方式如下：

```bash
source setup.env

bash 02_deepseek_v3_choice_head/scripts/run_pipeline.sh
bash 02_deepseek_v3_choice_head/scripts/run_train.sh
bash 02_deepseek_v3_choice_head/scripts/run_eval.sh
bash 02_deepseek_v3_choice_head/scripts/start_web.sh
bash 02_deepseek_v3_choice_head/scripts/start_quiz.sh
```

这些命令分别对应：完整流程、单独训练、单独评估、模型推理界面、人机答题界面。

### 5.2 批量运行多个实验模块

```bash
bash run_module_batch.sh list
bash run_module_batch.sh eval 00_baseline_gt_sft 02_deepseek_v3_choice_head
bash run_module_batch.sh pipeline 00_baseline_gt_sft 02_deepseek_v3_choice_head
```

### 5.3 夜间 API 任务

```bash
bash run_night_api_tasks.sh
```

该脚本用于夜间批量调度 API 教师标签生成任务。

## 6. 程序调用方式

### 6.1 推荐调用原则

对于普通用户，建议优先使用各模块目录下的 shell 脚本，而不是直接调用底层 Python 文件。原因如下：

1. shell 脚本已封装环境变量和目录路径。
2. shell 脚本已按论文实验约定组织输入输出。
3. 更便于实验复现和批量运行。

### 6.2 常用 Python 脚本直接调用示例

#### 6.2.1 模型评估

```bash
python shared/evaluate_model.py \
  --base_model models/Qwen2.5-7B-Instruct \
  --adapter_dir 02_deepseek_v3_choice_head/outputs/best \
  --test_data 02_deepseek_v3_choice_head/data/test.jsonl \
  --wrong_log logs/test_wrong.jsonl
```

#### 6.2.2 启动人机答题界面

```bash
python shared/quiz_app.py \
  --test_data 00_baseline_gt_sft/data/test.jsonl \
  --host 0.0.0.0 \
  --port 7870 \
  --title "医学选择题测试"
```

#### 6.2.3 启动模型推理界面

```bash
python shared/serve_model_app.py \
  --base_model models/Qwen2.5-7B-Instruct \
  --adapter_dir 02_deepseek_v3_choice_head/outputs/best \
  --host 127.0.0.1 \
  --port 7860 \
  --title "Dental Model App"
```

#### 6.2.4 生成 API 教师标签

```bash
python shared/generate_teacher_labels_api.py \
  --dataset 02_deepseek_v3_choice_head/data/train.jsonl \
  --candidate shared/teacher_candidate.sample.json \
  --system_prompt shared/system_prompt_mcq.txt \
  --output 02_deepseek_v3_choice_head/data/teacher_train.jsonl \
  --resume
```

## 7. Python 文件功能说明

以下内容说明仓库中主要 Python 文件的功能。

### 7.1 根目录工具脚本

- check_docx.py：检查指定论文 docx 的目标段落与表格内容。
- check_docx_raw.py：直接读取 docx 的 XML 内容，检查页面尺寸和节设置。
- check_docx_v2.py：按关键字扫描论文 docx，用于定位旧表述和异常数字。
- check_final.py：综合检查最终论文 docx 的页面和页边距信息。
- check_final_v4.py：基于 python-docx 检查论文节、边距和样式。
- check_para_details.py：输出指定段落的 run 详细结构。
- check_para_runs.py：检查指定段落的全部 run 文本分段。
- check_raw_v2.py：从底层 XML 中搜索页尺寸和页边距信息。
- check_styles.py：检查 docx 样式定义，例如字体和字号。
- check_table_runs.py：检查表格单元格的 run 分段。
- check_tables.py：扫描论文表格内容，定位关键数值或关键文本。

### 7.2 scripts 目录脚本

- resplit_dental_data.py：对牙科小数据集进行重新划分。
- resplit_fulldata.py：对 CMExam 全量数据进行重分割，生成训练集、验证集、测试集和牙科子集。

### 7.3 shared 目录脚本

#### 训练与蒸馏脚本

- train_gt_sft.py：使用标准答案进行 GT SFT 训练。
- train_choice_head_distill.py：实现 Choice-Head 蒸馏训练，是本系统核心脚本。
- train_whitebox_distill.py：实现白盒 KL 蒸馏。
- train_rationale_sft.py：使用推理链数据进行监督微调。
- train_alpha_distill.py：实现 α-散度蒸馏。
- train_boundary_filter_distill.py：实现边界过滤蒸馏。
- train_adaptive_alpha_distill.py：实现样本级自适应 α 蒸馏。
- run_two_stage_training.py：按顺序运行 Stage 1 蒸馏和 Stage 2 GT 精校。

#### 评估与汇总脚本

- evaluate_model.py：统一评估模型在测试集上的准确率。
- teacher_eval_summary.py：汇总教师评测结果。
- external_benchmark.py：统一评估外部模型表现。
- benchmark_doubao_models.py：对多个豆包候选模型进行基准测试。

#### 教师标签与软标签脚本

- generate_teacher_labels_api.py：调用 OpenAI 兼容 API 生成教师标签。
- generate_teacher_labels_local.py：使用本地模型生成教师标签。
- generate_teacher_labels_local_logprobs.py：生成带 logprobs 的本地软标签。
- generate_teacher_labels_vllm.py：使用 vLLM 后端生成教师标签。
- generate_teacher_cot.py：生成教师推理链数据。
- generate_teacher_soft_labels_multivote.py：生成多教师投票软标签。
- prepare_soft_labels.py：预处理软标签数据。
- merge_teacher_soft_labels.py：合并多个教师软标签文件。
- apply_temperature.py：对教师概率分布执行温度缩放。

#### 数据构造与分析脚本

- build_selective_distill_dataset.py：构造蒸馏训练数据集。
- fuse_multivote_teachers.py：融合多教师投票结果。
- ensemble_majority_vote.py：执行多数投票集成。
- audit_and_tag_source.py：审计数据来源并加标签。
- fisher_rao_analysis.py：进行 Fisher-Rao 信息几何分析。
- manifold_curvature_analysis.py：进行流形曲率相关分析。

#### Web 与服务脚本

- serve_model_app.py：启动模型推理 Web 页面。
- quiz_app.py：启动人工答题 Web 页面。

### 7.4 模块内部 Python 脚本

- 15_fulldata_resplit/scripts/run_eval_dual.py：对全量测试集和牙科子集进行双口径评估。
- 16_llama70b_choice_head/scripts/run_eval_dual.py：对 Llama-70B 路线执行双测试集评估。

### 7.5 文档与论文辅助脚本

- docs/gen_comparison_slide.py：生成实验对比 PPT 页面。
- thesis/generate_result_figures.py：生成论文结果图表。
- thesis/答辩/generate_thesis_defense_ppt.py：自动生成论文答辩 PPT。

## 8. 推荐使用流程

建议首次使用本系统时，按以下顺序操作：

1. 安装依赖并配置 setup.env。
2. 执行 source setup.env 和 bash check_env.sh。
3. 先运行 Module 00 作为环境验证。
4. 再运行 Module 02 复现最佳 7B 蒸馏方案。
5. 如需更高统计可靠性，继续运行 Module 15。
6. 如需跨架构蒸馏对比，运行 Module 16。
7. 如需展示系统效果，启动 Web 页面或 Quiz 页面。

## 9. 常见问题

### 9.1 程序无法启动

常见原因包括：

- 未执行 source setup.env
- 模型路径配置错误
- API Key 未配置
- GPU 显存不足
- Python 依赖未安装完整

### 9.2 为什么优先推荐 shell 启动脚本

因为 shell 启动脚本已经统一了路径、配置和输出目录，更符合论文实验复现方式，也能减少参数配置错误。

### 9.3 哪些内容不会随仓库一起提交

以下内容通常需要用户本地重新生成或本地保留：

- 模型权重目录 models
- 训练输出目录 outputs、runs
- 教师标签文件 teacher_*.jsonl
- 本地环境变量文件 setup.env
- 运行日志目录 logs、batch_logs、night_logs
