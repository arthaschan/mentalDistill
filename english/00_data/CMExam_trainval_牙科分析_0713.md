# CMExam train.csv / val.csv 牙科数据可用性分析（2026-07-13）

> 触发：用户指出 english/dataset/ 下的 3 个 CSV 是 CMExam 原始数据，其中 test_with_annotations.csv
> 是牙科子集来源，但 train.csv / val.csv 从未提取使用。分析这两个文件的牙科数据是否有价值。

## 1. 三个 CSV 的结构差异（核心发现）

| 文件 | pandas 真实行数 | 列 | 有学科标注? |

| train.csv | 54497 | Question, Options, Answer, Explanation | ❌ 无 |

> 注：`wc -l` 对 train.csv 数出 27 万行是假象——题干含换行符；pandas 正确行数 54497。
> 你的中文牙科子集(830题)= test 集里 `Medical Discipline=="口腔医学"` 筛出。
> train/val **没有学科列**，这就是你当初没法直接提牙科的根本原因。

## 2. train/val 牙科题量（只能靠中文牙科关键词过滤）

关键词表：`牙|口腔|龋|齿|根管|牙周|牙髓|正畸|义齿|种植体|颌|唾液|涎|黏膜|磨牙|切牙|尖牙|乳牙|恒牙|釉质|牙本质|牙龈|拔牙|咬合`

**关键词精度/召回（在有标注的 test 集上实测）**：
- 精度 83%（命中431题中356题真是"口腔医学"标注）
- 召回 43%（830 真牙科题只命中356）→ 会漏掉约 57% 真牙科、混入约 17% 杂科

**train/val 估算牙科量**：
| 文件 | 关键词命中 | 估真牙科(×0.83) |
|---|---|---|
| train.csv | ≈4479 | **≈3717** |
| val.csv | ≈526 | **≈436** |
| 合计 | ≈5005 | **≈4150** |

是现有中文牙科子集(830题)的约 5 倍。

## 3. 泄漏检查（关键，结论：干净）
- train/val 关键词牙科题 与 test 牙科题(830)重叠：train 仅 **1**、val **0** → 几乎零泄漏，可安全作训练数据。
- train 与 test 整体题目重叠：319（占比极低，去重即可）。

## 4. 使用价值判定（分两条线，有语言硬约束）

这 3 个 CSV 是**中文 CMExam**，不是英文。

- 对【本轮英文牙科项目】：❌ **不可并入**。中文题混进英文数据集造成语言混淆，毁主结论；且英文项目 test_ukus(94题)本就全牙科，"学生超越教师"是原生成功条件，不需要中文数据。
- 对【中文论文——牙科子集未超越教师的遗憾】：✅ **高价值**。原论文只在全医科成功、牙科子集(125题canonical=82.13%)失败，很可能因牙科训练数据太少。补入 ~4150 中文牙科题训"牙科专精学生"，有望首次在牙科子集上超越教师——即用户说的"更有价值"的结果。

## 5. 关键词过滤的诚实局限
- 召回仅 43%：会漏掉大量无明显关键词的牙科题（如纯病例描述）。若要更全，需训一个学科分类器或用 LLM 打学科标签（成本更高）。
- 精度 83%：混入约 17% 邻近学科（如口腔相关的病理/药理）。用于训练可接受（噪声小），但若要作干净测试集需人工核。

## 6. 结论
train.csv / val.csv **有可观牙科数据(~4150题)且泄漏干净**，但**只对中文论文有价值**（语言约束），不能进本轮英文项目。已列入计划作为"中文牙科专精学生冲刺超越教师"的第 2 篇实验。
