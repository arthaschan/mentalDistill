# 干净外部RAG评估结论（2026-07-14）

> 用新建的29128条外部牙科知识库(PubMed+Dentistry_RAG+StatPearls+Wiki)重做RAG，语料与测试题(BoF/NBDE)不同源。

## 结果：+0.00pp
- base 14B 闭卷 65.96% → +RAG top3 **65.96%（+0.00pp）**
- 对比之前**同源**语料 +11.7~21pp。

## 诊断：两个叠加问题（都在检索侧，非"补知识"思路错）

### 问题1：embedding 严重各向异性
- 随机 passage 对之间余弦均值 = **0.904**（正常应 <0.3）。
- 后果：S-PubMedBert 空间里"啥都和啥像"，检索 top-k 几乎无区分度，max-sim 中位数虚高到 0.945。
- 检索到的是"话题相关"但非"答案相关"的段落。

### 问题2：语料是"研究叙述"不是"答案事实"
- 例：问"serial extraction 拔牙顺序"，检索回"premolar extraction 广泛用于矫正拥挤…"（相关话题，但没给顺序这个事实）。
- PubMed 摘要是研究结论/背景，**不直接陈述考点事实**；教材/StatPearls 稍好但仍偏叙述。

## 关键诚实结论（修正之前的判断）
- 之前同源 +21pp **主要是泄漏**：BoF/NBDE 的解析文本 literally 写了这道题的答案。
- **干净外部 RAG 当前配置 = 0 增益**。这才是可投的诚实数字。
- 但这**不推翻"瓶颈是知识"的诊断**——问题出在"检索没找对知识"，不是"补知识无用"。是**可修的检索质量问题**。

## 可修方向（下一步，按成本排序）
1. **换低各向异性 embedding**：BGE-large-en / GTE-large（通用但各向异性低），或对当前向量做 whitening/mean-centering。成本低，先试。
2. **换答案型语料**：StatPearls/教材的"疾病→特征→处理"结构化段落比 PubMed 研究摘要更适合答题；可只用 Dentistry_RAG+StatPearls，去掉 PubMed 研究摘要噪声。
3. **重排序(rerank)**：检索后用 cross-encoder 重排，挑真正答案相关的段落。
4. **oracle 上界先验**：先算"若检索到含正确答案的段落，模型能对多少"——判断天花板，再决定值不值得修检索。

## 判断
- RAG 不是死路，但**当前 embedding+语料组合无效**。修检索(换embedding/换语料/rerank)是明确的下一步。
- 若修完仍≈0，则说明这些外部源确实不含考点事实，需转向 DAPT(继续预训练把知识写进参数)或更权威的牙科教材语料(需你机构提供)。
- **诚实边界**：不宣称"RAG提分"，当前干净结果是+0；修检索后重测才有结论。
