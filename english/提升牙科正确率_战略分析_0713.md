# 如何进一步提升医学/牙科 MCQ 正确率 — 战略分析（2026-07-13）

> 触发：用户问——①数据已证明无法再增加 ②很多方法都试过了 ③接下来怎么办。
> 本文档诚实分析瓶颈本质，并给出未被触碰的新轴。

## 1. 先看清楚：21个模块 + α扫描，其实只动了「一个轴」

| 已试方法(00–20 + α扫描) | 本质 |
|---|---|
| GT SFT / 白盒KL / Choice-Head / α散度 / 自适应α / 边界过滤 | **如何加权 教师分布 vs 金标准** |
| DeepSeek/Doubao/Kimi/Qwen14B/32B/Llama70B 换教师 | **换监督来源** |
| 7B/14B/Qwen3 换学生、多seed集成、自蒸馏 | **换/组合模型** |
| 多教师融合/多票/自一致性 | **组合多个监督** |
| CoT推理链蒸馏(模块12) | 把教师CoT蒸进**训练** |

**共同点：全部是"重排监督信号"——在 MCQ 格式上、闭卷参数化地、重新分配教师和金标准的权重。**
α消融已证明这个轴到头了：α=0(纯金标准SFT)最优，加教师KL只会更差。**再在这个轴上调参数不会有增量**——这就是为什么牙科卡在~82%、全科卡在~89%。

## 2. 瓶颈的真正本质

牙科题错的不是"监督信号不够好"，是**学生参数里没有那条牙科知识**。
- 证据：教师DeepSeek-V3在英文牙科88.3%、中文牙科也强；学生零样本地板仅68%。差的是**知识**，不是**决策对齐**。
- Choice-Head的增益机制是"把已有知识对齐到5选1决策空间"，典型+5pp——它**不注入新知识**，所以填不平20pp的知识沟。
- 牙科是**查表/事实密集**领域(药物剂量、分类、器械、解剖)，比推理密集领域更依赖"知道不知道"。

## 3. 未被触碰的三个新轴（真正可能提分的方向）

### 轴A：检索增强(RAG) —— 最大空白，最该先做 ★★★
- 全部21模块都是**闭卷参数化**。牙科事实类题目最适合开卷检索。
- 仓库已有 `shared/rag_index/` 但从未接入蒸馏/评估主线。
- 做法：把三本教材的**解释文本**(BoF/NBDE/MCQ每题都有explanation)+ 牙科教材段落建向量库；推理时检索top-k注入prompt，学生"开卷答题"。
- 为什么可能成：注入的是学生参数里没有的知识，直接补知识沟；对事实类牙科题增益应显著。
- 论文价值：从"蒸馏"转向"检索增强的轻量牙科QA"，且可对照"闭卷蒸馏 vs 开卷检索"——有故事。
- 预实验(便宜)：拿现成student，test_ukus上加/不加检索对比，零训练即可看上界。

### 轴B：领域自适应继续预训练(DAPT) —— 加知识而非加监督 ★★
- 所有模块都在**MCQ格式**上SFT/蒸馏，从没在**牙科教材散文**上继续预训练。
- 做法：先用牙科教材正文(三本书的解释段+更多教材prose)做continued-pretraining(LM loss)，再Choice-Head SFT。
- 为什么可能成：DAPT是公认的领域知识注入手段，把牙科知识写进参数，再对齐决策空间。
- 成本：比蒸馏重(需更多语料+算力),但单H100可做14B LoRA continued-pretrain。
- 风险：牙科纯文本语料量可能不够(教材有限)；需先估语料规模。

### 轴C：测试时计算(test-time compute) —— 不改训练，改推理 ★★
- 模块12是把CoT蒸进训练；**没试过推理时**让学生自己CoT+自一致性投票(self-consistency)。
- 做法：学生对每题生成多条推理链→多数投票；或用熵信号在低置信题上触发更多采样/检索。
- 为什么可能成：test-time compute被证明能显著提准确率(o1式),尤其难题；且天然结合你的**熵-难度moat**(高熵牙科题多算)。
- 成本：只增推理开销,零额外训练。可立即在现成student上试上界。

## 4. 结合你已有资产的最优组合(建议路径)

**熵-难度moat(已建) + 轴A检索 + 轴C测试时计算 = 一条自洽的新论文线**：
用熵定位"学生该题在猜"(你已验证熵=难度)→ 对这些高熵牙科题**触发检索(轴A)+多采样(轴C)**→ 低熵题直接答。
- 这不是"又一个蒸馏方法"(红海)，是"**用不确定性信号自适应地决定何时开卷/何时多想**"——审计/诊断型生态位(你的主场)。
- 可证伪、便宜预实验、结合已有moat、避开"监督信号重排"红海。

## 5. 诚实排序(经济价值×论文价值×预实验成本)

| 方向 | 提分潜力 | 论文新颖 | 预实验成本 | 建议 |
|---|---|---|---|---|
| 轴A RAG检索 | 高(知识注入) | 中高(闭卷vs开卷对照) | 低(现成student可估上界) | 🥇 先做零成本上界 |
| 轴C 测试时计算 | 中高(难题) | 中(结合熵moat则高) | 低(纯推理) | 🥈 与A并行估上界 |
| 熵引导的A+C组合 | 高 | 高(诊断生态位) | 中 | 🥇 主推论文线 |
| 轴B DAPT | 中(受语料限) | 中 | 中高(需语料+训练) | 🥉 语料够再做 |
| 继续调蒸馏超参 | ~0(已到头) | 低 | — | ❌ 不做 |

## 6. 立即可做的零成本预实验(不占用当前GPU队列)
1. 轴A上界：现成14B student + test_ukus，每题检索三本书explanation的top-3注入prompt，测加检索前后准确率差。若+5pp以上→RAG值得做。
2. 轴C上界：现成student对test_ukus每题采样5条CoT多数投票，对比单次。
两个都不训练、可在诊断实验跑完后排队，几十分钟出GO/NO-GO。

## 7. 一句话结论
**"方法试过了"其实只试过一个轴(重排监督信号),而它已被α消融证明到头。真正没碰的是"给学生加知识"的轴:检索(RAG)、继续预训练(DAPT)、测试时计算。其中"用你已验证的熵信号自适应触发检索+多采样"最契合你的诊断型生态位,是提分与论文双高的下一步。**
