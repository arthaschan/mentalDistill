# 概念解释（大白话，给非技术读者）

> 汇报文档 english/进展汇报_给老师_0714.md 里用到的词，凡不是标准术语的都在这里解释。
> 每个概念：先打比方 → 再精确定义 → 再说它在我们研究里的作用。

---

## 1. 知识沟（我自造的词，非标准术语）

**打比方**：两个学生考牙科。老师（大模型 DeepSeek-V3）真的背过牙科教材，知道"某颗牙的神经叫什么、某个药的剂量是多少"。学生（小模型 Qwen）没背过这些，光靠"考试技巧"answer。技巧再好，不知道的知识点还是不会——这中间差的那块**就是"知识沟"**。

**精确定义**：学生模型的参数里**缺少**某个领域（这里是牙科）的事实性知识，导致它无论怎么训练答题技巧都答不对那些需要专门知识的题。差距大小 = 教师准确率 − 学生天花板。

**在我们研究里**：教师 88.3%、学生最高 75.2%，差 13 个百分点。我们做了对照实验，证明这 13 分里只有 2 分是"训练数据分布不对"，剩下 **11 分是学生真的不知道那些牙科知识**。所以叫"知识沟"——不是训练方法不好，是脑子里没那块知识。

**标准术语对照**：学界叫 "knowledge gap" 或 "parametric knowledge limitation"（参数化知识局限）。

---

## 2. 自一致性（半标准术语，英文 self-consistency，需解释）

**打比方**：一道难题，让学生**换 5 种思路各做一遍**，然后看哪个答案出现次数最多，就交哪个。一个人反复想几遍、少数服从多数，比只想一遍更可靠。

**精确定义**：让模型对同一道题，用带随机性的方式**生成多条"解题推理过程"（每条可能思路不同）**，每条推理最后给一个答案，然后**对这些答案做多数投票**，票最多的作为最终答案。英文原论文叫 self-consistency（Wang et al., 2022）。

**在我们研究里**：让 14B 模型每道牙科题想 5 遍（K=5）再投票，准确率从 66% 提到 73.4%（+7.45 分）。说明模型有些错误不是"不知道"，而是"想一遍容易出错、多想几遍能纠正"。

**为什么算"半标准"**：self-consistency 是学界公认术语，但中文"自一致性"直译对非技术读者不直观，所以要解释。

---

## 3. 零知识库（我自造的说法，非标准术语）

**打比方**：考试分两种——
- **开卷**：允许翻牙科教材（= 有"知识库"，模型答题前先去书里检索相关段落）。
- **闭卷**：不许翻任何书，全靠脑子（= "零知识库"，不给任何外部资料）。

**精确定义**："零知识库"= 不给模型任何外部参考资料，只靠它自己参数里已有的知识答题。与之相对的是 RAG（检索增强），那是"给它一个可查的资料库"。

**在我们研究里**：我想强调"自一致性"这个方法的一个优点——它**不需要准备任何外部资料库**，纯靠让模型多想几遍就能提分。所以适合"手头没有牙科教材电子库"的场景。而 RAG 提分更多，但**必须先有一个牙科知识库**可查。

**更准确的说法**：应该说"闭卷设定（closed-book）"或"无外部检索"。以后我在正式文档里改用"闭卷"。

## 4. 顺带解释汇报里其他可能不熟的词

| 词 | 大白话 |
|---|---|
| **RAG / 检索增强** | 模型答题前，先从一个资料库里"搜"出跟这道题相关的段落，贴在题目前面一起读，相当于"开卷考试"。全称 Retrieval-Augmented Generation。 |
| **蒸馏 / 知识蒸馏** | 用一个强的大模型（老师）教一个小模型（学生）：让学生模仿老师的答案/判断，把老师的本事"浓缩"进小模型。好处是小模型便宜、能部署。 |
| **Choice-Head** | 我们的方法名。选择题只有 A/B/C/D/E 五个出口，我们只在这 5 个字母上算损失、对齐监督，而不是让模型自由生成一大段话。相当于"把答题压缩到 5 选 1 这个窄决策上"。 |
| **α（alpha）** | 一个开关旋钮：控制训练时"听老师的软判断"占多少、"照标准答案"占多少。α=0 表示完全照标准答案（不听老师）；α=1 表示完全模仿老师。我们发现 α=0 最好。 |
| **软标签 / 教师分布** | 老师不只给"答案是B"，还给"我 70% 觉得 B、20% 觉得 C、10% 其他"这种带把握程度的判断，这叫软标签。 |
| **零样本 / zero-shot** | 模型**完全没经过我们训练**、直接拿来答题的原始水平，作为"地板"基准。 |
| **主测试 test_ukus** | 我们最看重的那份考卷：94 道纯英美牙科题，学生的"高考成绩"以它为准。 |
| **跨来源泛化** | 拿印度题训练的学生，去考英美题，看还行不行——测"换个地方出的题还灵不灵"。 |
| **分布错配** | 训练用的题（印度风格）和考试的题（英美风格）来源不同、风格不一样，导致学生"水土不服"。 |
| **prior-art 查重** | 投论文前，搜一遍别人有没有做过一样的东西，确认我们的新意还在。 |

## 5. 一句话把整个故事讲给外行

> 我们想用便宜的小模型（学生）学会强大模型（老师）的牙科答题本事。发现无论怎么调教学方法，学生都追不上老师，差了 13 分。查明原因：**不是教学方法不好，是学生脑子里根本没背过那些牙科知识（知识沟）**。于是换思路：要么考试时让它"开卷"翻牙科书（RAG，提分最多），要么让它"同一题多想几遍投票"（自一致性，不用翻书也能提分）。这两招在初步测试里都有效——说明下一步该往"给它补知识"走，而不是继续改教学方法。
