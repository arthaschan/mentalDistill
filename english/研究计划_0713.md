## 2. 反思：AIEA/CMExam 阶段的教训（决定本轮策略）

来自 主文档4 + 评审技能，逐条转成本轮纪律：

1. **投 GPU 前先算零成本上界**：融合曾被「Qwen 全能」误杀；本轮英文融合先用现成 logprobs 做 oracle 上界（≥2pp 才训，<0.5pp 直接否）。
2. **生态位=审计/验证，不是发明新方法**：不追「又一个蒸馏新模块」，主打「把中文验证过的诊断迁到英文，看还成不成立」。
3. **外部金标准救命**：熵检测会被质疑「不就是置信度校准？」——必须用**不依赖模型自身置信**的金标准锚定（牙科题的专科分区/难度、跨模型共识错误数、题目内在属性）。
4. **数据现实先审**：先查 argmax==GT 比例是否=教师真实准确率（防 GT 锚定）、每特征方差是否>0（防常数软标签）。本轮英文软标签必须重新生成、现场校验。
5. **别开第 10 个方向，闭环一篇**：本轮目标是**一篇可投稿的英文牙科蒸馏论文**，不是又铺一堆子方向。
6. **查重要像审新方法一样严**：英文牙科蒸馏 + 融合复活 + 熵难度，投稿前用 arXiv+Semantic Scholar 三层查重。
7. **诚实定级**：单领域、信号可能归约到熵/融合，天花板是中等会议 findings / 医学AI期刊 / 优秀硕士，非顶会。提前说清。

## 3. 三阶段模型筛选（用户要求的「先做一轮大模型筛选」）

全部 forward-pass only，单 H100 顺序跑，零训练成本。

**筛选一：能力筛（zero-shot 准确率 + 熵）**
对全部本地教师 + API 教师，在英文牙科题上跑 5 选 1 logprobs，产出：
- 每教师总准确率（英文牙科教师先验表，git 冻结）
- 每教师 × 牙科分区（口腔外科/牙体牙髓/牙周/修复/正畸/儿牙/口腔病理…）的分区准确率
- 每题的熵、top1-top2 margin（供后续难度分析）
淘汰线：总准确率 < 学生 baseline 或 < 55% 的教师不进融合池（弱教师历史上蒸馏为负）。

**筛选二：互补性筛（这是融合复活的关键判据，零成本）**
用筛选一的分区准确率矩阵，检查是否存在「无单一霸主」：
- 若某教师全分区最强 → 融合大概率死（复刻中文），走 3b。
- 若不同教师各擅胜场 → 融合有戏，进筛选三。

**筛选三：融合 oracle 上界（GO/NO-GO 闸门）**
纯分析，不训练。按「每题选当时最可信教师的标签」构造 domain-routed / entropy-routed oracle 软标签，估算融合教师集成的准确率上界：
- 上界 − 最强单教师 ≥ 2pp → **GO**（走 3a 融合蒸馏）
- < 0.5pp → **NO-GO**（走 3b 单教师复刻）
- 中间 → 记录，作二级实验。

## 4. 主实验（按闸门分叉）

**路径 3a：多教师融合蒸馏（若融合 GO）**
- 用筛选选出的互补教师，生成多票软标签 → 合并（静态/熵路由/自一致性，复用 shared 现成脚本）。
- Choice-Head 两阶段蒸馏 → Qwen2.5-7B / 14B 学生。
- 对照臂：最强单教师蒸馏、random 融合、GT-only SFT baseline。
- **头号卖点**：跨语言对照——同一融合方法在中文(CMExam)+0.00pp、在英文牙科+Xpp，用「教师阵容是否有霸主」解释，落成一条可证伪的机制结论。

**路径 3b：单最强教师蒸馏 + 熵-难度外部验证（若融合 NO-GO）**
- 复刻 AIEA：最强教师(DeepSeek-V3 或最强本地)→ 7B/14B Choice-Head，看英文牙科上学生能否追平/超越教师。
- moat：把「教师熵=客观难度」搬到英文牙科，用外部金标准锚定（牙科分区难度 + 跨模型共识错误数 + 题长/否定词 null 对照），证明不是表面 artifact、不是纯校准。
- 这条即便融合死也**独立成篇**（英文专科版的诊断迁移，接 P3 跨域主线）。

两条路径共用：3 seed、置信区间、val 选点/test 报告、canonical eval prompt 一致性。

## 5. 数据处理（Phase 0，零 GPU，本轮第一步）

1. 抽取 Best of Fives → 结构化 JSONL：{stem, options[A-E], answer, explanation, 分区}。
2. MCQs for Dentistry：多选题单列，评估「能否转单选」或单独作多标签二级集。
3. NBDE：低优先，尝试抽可用单选，抽不出就只作背景语料。
4. 数据现实审计：题量、分区分布、答案分布是否偏、去重、与 CMExam/MedQA 是否重叠。
5. 切分 train/val/test；小样本（~300）下考虑 few-shot 教师标注 + 交叉验证，明确「训练集偏小」为诚实边界。

## 8. 诚实风险清单（提前列，投稿前逐条回应）

- 训练集偏小(~300 单选)：小样本蒸馏稳定性存疑 → 用 few-shot 标注 + 多 seed + 交叉验证兜底，声明边界。
- 融合复活可能不成立：英文牙科上也可能某强教师(如 GPT/DeepSeek)通吃 → 那就诚实走 3b，融合作负结果消融。
- 「熵=难度」被质疑纯校准：靠外部金标准（分区/共识/内在属性）+ null 对照回应。
- 单领域(牙科)、单语言方向 → 天花板中等会议/医学AI期刊，不夸大。
- 数据版权：三本书为受版权教材，仅内部研究抽题做标签，不发布原文；发布时遵 reproducible-research-repo 脱敏。

## 10. 执行进展与计划更新（滚动，2026-07-13 晚）

### 10.1 CP2 关键决策（已落定，见 02_fusion_oracle/CP2_决策_融合上界.md）
- **融合判定 NO-GO**：8教师英文牙科筛选。可实现融合上界 −0.16pp（oracle作弊版+3.3pp但不可廉价捕获）。
  跨语言机制对照升级为"融合在中文死(无互补)、英文也死(有互补但不可捕获)"——更抗审稿的诚实结论。
- **主教师锁定 DeepSeek-V3 = 82.86%**（8教师断层第一，和中文一致仍是冠军；Qwen32B 73.9% 第二）。
- **走路径 3b**：单最强教师(DeepSeek-V3) → Choice-Head → 7B/14B 学生 + 熵-难度外部验证 moat。

### 10.2 α=0 消融结论纳入（关键，来自中文 AIEA 消融 aiea/alpha_ablation_results.md）
- 中文实验已证：**α=0（纯CE/SFT）最优**，canonical full=89.14% > α=0.35的88.67% > 教师87.18%；KL权重越高越差(纯KL 86.21%最差)。
- 归因：超越教师靠**决策空间监督**(Choice-Head)，非 dark-knowledge 蒸馏(教师-金标准仅12.2%不一致+仅5类)。
- **本轮英文主实验以 α=0 为头条臂**，跑 α扫描{0.0, 0.35, 1.0}×{7B,14B}×3seed=18臂，验证"中文KL有害结论能否在英文牙科复制"。

### 10.3 熵-难度外部验证（已完成，02_fusion_oracle/entropy_difficulty.md）
- H4：7教师高熵档错误率是低熵档的 3–6.6 倍（无一失效）。
- 5d：平均熵↔跨模型共识难度 ρ=0.69（p=0.001），比中文 0.35 更强。
- null对照：熵vs题长 ρ=0.05、vs否定词 ρ=0.09（≈0，排除表面artifact）。moat 成立。

### 10.4 prior-art 查重（arXiv一轮，priorart_verdict.md；S2限速待补）
- L1 英文牙科MCQ蒸馏=应用空白；L2 融合负结果需对 One Teacher is Enough?(2021) 划界；L3 熵↔共识难度=最强新颖点(零命中)。

### 10.5 数据集（方案B，见 dataset/DATASET_B.md + 00_data/数据集查找计划_0713.md）
- 训练池 2551（UK/US 447 + MedMCQA 2104），val 95，主测试 test_ukus 94（纯净），跨来源 test_medmcqa 371。
- MedMCQA 是唯一大规模英文牙科真源(train+val共2475提纯题)；HEAD-QA/瑞典/NBDE设计类均排除(见查找计划)。
- 教师标签：DeepSeek-V3 全池已标(0缺失)，教师训练池准确率71.66%。
