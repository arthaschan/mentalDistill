## 摘要

【占位：实验完成后写，约 200 字】

要点骨架：
- 问题：能否把中文全科医学上已验证的「学生超越教师」，迁移到英文全科医学。
- 方法：教师预评估（DeepSeek/Gemini/Llama + 本地教师零样本筛选）→ 选最强教师做基准；Choice-Head 蒸馏（α=0 纯决策空间监督）训练 Qwen2.5-32B/14B 学生；熵-难度外部验证作 moat。
- 主要结果：【占位】学生 32B α=0 在 MedQA/MedMCQA/MMLU 组合上【达到/未达到】教师水平。
- 关键发现：α=0 最优（跨语言第三次复制）；教师预评估可提前判定 headroom；本地 Llama70B 在训练集上强于 DeepSeek（标签质量反转）。

## 1. 引言

### 1.1 背景与动机
- 医学 MCQ（MedQA/MedMCQA/MMLU）是 LLM 医学能力的标准评测。
- 知识蒸馏把大教师能力压进小模型，但多数工作止步于「学生接近教师」。
- 本项目中文实验已实现「学生超越教师」：CMExam 全科 14B 学生 89.14% > DeepSeek 教师 87.18%。
- **核心问题**：这一现象能否跨语言复制到英文全科医学？还是中文特例？

### 1.2 已有跨语言线索（本项目的英文牙科实验）
- 英文牙科专科：学生 75.18% vs 教师 88.30%（**未超越**，headroom 20pp）。
- 规律假说：**宽领域能超越、专科难超越**（中英双语牙科均未超越，中文全科超越）。
- fullEnglish 是宽领域（20 万题、多来源），落在「能超越」一侧 → 本实验检验该假说。

### 1.3 贡献
1. 首次在英文全科医学 MCQ 上系统检验「学生超越教师」，与中文形成跨语言对照。
2. 教师预评估方法：零样本筛选即可提前判定 headroom，指导主教师选择。
3. 发现训练集/测试集上教师相对强弱可反转（Llama70B 训练集 86.14% > DeepSeek 79.50%，测试集反之）。
4. 熵-难度 moat 在英文全科再次成立（ρ=0.629），跨语言跨领域稳健。
5. 多教师融合在英文全科再次 NO-GO（-0.50pp），与中文/英文牙科构成机制对照。

## 2. 相关工作

### 2.1 医学 MCQ 基准
- MedQA（USMLE）、MedMCQA（印度 NEET）、MMLU-med（12 科目）、PubMedQA（判断题）。
- 已有 LLM 在 MedQA 上的成绩（GPT-4/Med-PaLM 等）作为背景。

### 2.2 LLM 知识蒸馏
- 经典 KD（Hinton 2015）、LLM 蒸馏（Gou 2021 综述）。
- 本项目 Choice-Head：只对齐 A-E 决策空间，非全词表 logits。

### 2.3 教师筛选与多教师
- 「One Teacher is Enough?」（2021）划界：多教师未必优于单最强。
- 本项目三语言结论：融合在中文死（无互补）、英文牙科死（互补不可捕获）、英文全科死（单一霸主）。

### 2.4 熵-难度（校准/不确定性）
- 教师熵作为难度代理，需外部金标准（跨模型共识）避免「纯校准」质疑。

## 3. 方法

### 3.1 数据
- 训练池：MedQA train(10178) + MedMCQA train(抽样 10000) + MMLU validation(310) = 20488 题。
- 验证：MedQA dev(1272)。
- 测试（held-out）：MedQA test(1273) / MedMCQA val(4183) / MMLU test(2837)。
- 泛化评测：PubMedQA(1000, 判断题, 蒸馏全程未用)。

### 3.2 教师预评估（Phase 1）
- 600 题零样本筛选（每测试集抽 200），产出教师先验表 + headroom。
- 教师：DeepSeek-V3(API)、Llama-3.3-70B(本地 vLLM)、Gemini(API)、Qwen32B/14B、Phi4、Gemma27B、Yi34B。
- 判据：headroom ≤ 8pp 有望超越（参照中文 3.6pp），> 8pp 偏难（参照英文牙科 20pp）。

### 3.3 Choice-Head 蒸馏（Phase 3）
- 学生：Qwen2.5-32B（主线）+ Qwen2.5-14B（消融）。
- 损失 `L = α·KL + (1−α)·CE`，只在 A-E 五个选项 token 上计算。
- 头条 α=0（纯 CE / 决策空间监督），α 扫描 {0, 0.35, 1.0} 复现「KL 越多越差」。
- LoRA r=16/α=32，1 epoch，3 seed(11/42/8)，选点 val、报告 test。

### 3.4 熵-难度外部验证（moat）
- 金标准 = 跨模型共识错误数（英文无人类难度标注）。
- H4（教师熵定位错误）、5d（熵 vs 共识相关）、5d-null（题长/否定词对照）。

### 3.5 融合 oracle（GO/NO-GO）
- majority_vote / conf_route / prob_avg / domain_route_CV 可实现上界。
- ≥2pp 走融合，<0.5pp 走单教师。

## 4. 实验设置

- 硬件：单 H100 NVL 95GB。
- 教师：DeepSeek-V3 主教师（key 实测有效）；Llama-3.3-70B-AWQ 本地 vLLM（免费）；Gemini 因地区/额度限制本轮缺席。
- 学生：Qwen2.5-32B-Instruct（LoRA）；Qwen2.5-14B 消融。
- 超参：batch 1×8(32B)/2×4(14B)，lr 1e-4，rank 16，epochs 1，deterministic。
- 教师标签：DeepSeek 硬标签→smooth_eps=0.25 软化；Llama70B 真实 logprobs。

## 5. 结果

### 5.1 教师筛选（已完成，CP1）
| 教师 | 总分 | MedMCQA | MedQA | MMLU |
|---|---|---|---|---|
| DeepSeek-V3 | 81.67 | 74.5 | 80.5 | 90.0 |
| Llama-3.3-70B | 79.50 | 70.0 | 80.5 | 88.0 |
| Qwen32B(学生) | 72.67 | 62.0 | 71.0 | 85.0 |
| Phi4 | 72.00 | 62.0 | 73.0 | 81.0 |
| Qwen14B | 67.83 | 57.5 | 66.5 | 79.5 |

- headroom = 9.00pp（临界，略高于 8pp）。
- DeepSeek 单一霸主（三个源全冠军）。

### 5.2 教师标签质量反转（已完成，重要）
- 训练集（15681 共同题）：Llama70B 86.14% > DeepSeek 79.50%。
- 测试集：DeepSeek 81.67% > Llama70B 79.50%。
- 分歧题正确归属：Llama70B 对 1954 vs DeepSeek 对 912。
- → DeepSeek 训练集标签仅 79.5% 干净，进一步支持 α=0（纯 GT）最优。

### 5.3 学生蒸馏主结果【占位】
- 32B α=0 ×3 seed：MedQA / MedMCQA / MMLU / 组合【占位】。
- 14B α=0 ×3 seed：【占位】。
- 与教师同集对比：【占位】。
- 头条判定：学生【超越 / 未超越】教师。

### 5.4 α 消融【占位】
- 32B α∈{0, 0.35, 1.0}：【占位】（预期 α=0 最优，第三次跨语言复制）。

### 5.5 熵-难度 moat（已完成）
- H4：高熵错误率是低熵的 4.7–8.9 倍。
- 5d：平均熵 vs 共识难度 ρ=0.629（p=0.001）。
- 5d-null：题长 ρ≈0、否定词 ρ=0.136。

### 5.6 融合 oracle（已完成，NO-GO）
- 可实现上界 gap = -0.50pp → NO-GO（融合死）。

### 5.7 PubMedQA 泛化【占位】
- 学生在 held-out 判断题上的表现 vs 教师。

## 6. 讨论

### 6.1 跨语言规律
- 中文全科（超越）vs 英文全科【占位】vs 英文牙科（未超越）vs 中文牙科（未超越）。
- 「宽领域能超越、专科难超越」是否在英文全科再次成立。

### 6.2 机制分析
- headroom 是超越与否的第一判据（中文 3.6pp 超越 / 英文牙科 20pp 未超越 / 英文全科 9pp【临界】）。
- 教师标签质量反转：API 教师（DeepSeek）在训练集上未必强于本地教师（Llama70B），α=0 规避了教师标签噪声。

### 6.3 局限
- MedMCQA 印度分布 vs MedQA 美国分布，分布泛化以分源报告缓解。
- Gemini 缺席（地区/额度），教师阵容以 DeepSeek + 本地为主。
