# 预判报告：14B 学生能否超越 DeepSeek 教师？

> 时间：2026-08-14（14B 对照实验尚未开始，本报告基于已完成的数据做预判）
> 结论：**预判 14B 学生不可能超越 DeepSeek 教师（81.67%）**，与用户预判一致。

---

## 一、核心数字（已落盘，非估算）

| 指标 | 数值 | 来源 |
|---|---|---|
| DeepSeek 教师（测试集零样本） | **81.67%** | 教师筛选 600 题（CP1） |
| 14B 学生零样本地板 | **67.83%** | 教师筛选的 Qwen14B 分数（同 600 题） |
| 14B headroom（教师−学生） | **13.84pp** | 上两行之差 |
| 中文 14B 蒸馏最大增益 | **+5.12pp**（83.55→88.67） | 中文全量实验（历史最大增益） |

## 二、推理链

1. 14B 零样本 67.83%，比 DeepSeek 低 **13.84pp**。
2. 中文实验里 14B 蒸馏的增益上限是 **+5.12pp**（且当时 headroom 仅 3.63pp）。
3. 即便英文 14B 蒸馏增益达到历史最大值 +5.12pp，学生也仅 67.83+5.12 = **72.95%**，仍比教师低 **8.72pp**。
4. 英文教师 headroom（13.84pp）远超中文（3.63pp），蒸馏增益通常随 headroom 增大而更难填平（英文牙科 20pp headroom 时学生差 13pp）。
5. **结论：14B 不可能超越教师**。要打平需 +13.84pp 增益，约为中文历史最大增益（5.12pp）的 2.7 倍，无先例支撑。

## 三、32B 学生的对比预判

- 32B 零样本 72.67%（比 14B 高 4.84pp），headroom = 9pp。
- 需 +9pp 增益才能打平；中文增益 5.12pp，但 32B 更强 + 训练数据 20K（中文 4.6K 的 4.4 倍），增益可能更大。
- **32B 是「临界」**：可能接近打平或略差，结果待主实验出。

## 四、14B 实验的价值（即便不超越）

1. **学生规模消融**：32B vs 14B 的增益对比，量化「学生规模」对蒸馏的影响。
2. **跨语言对照**：中文 14B 能超越教师（headroom 3.63pp），英文 14B 不能（headroom 13.84pp）→ 说明「能否超越」由 **headroom** 决定，不是语言本身；英文医学对教师和学生都更难。
3. 与「宽领域能超越、专科难超越」假说互证：英文全科对 14B 而言仍属「难超越」区间（教师太强）。

## 五、一句话

**14B 预判不超越（headroom 13.84pp 无法由 ~5pp 蒸馏增益填平）；32B 临界（headroom 9pp，结果待出）。真正决定「能否超越」的是 headroom，不是语言。**
