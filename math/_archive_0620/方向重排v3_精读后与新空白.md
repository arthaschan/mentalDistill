## 第二部分：新空白挖掘（竞品"明确没做"的）

精读三篇时，子代理逐条列出了它们的 Limitations 和 future work，这些正是**有人背书的空白**（作者自己承认没做）。逐个评估：

### 🆕 D7：直接验证"熵=可靠"假设的真伪（经济3/论文4）
- **来源**：GateKD 把"低熵=可靠"当公理，作者自承"置信度可能 miscalibrated，列为未来工作"。
- **我们做**：这正是我们 5d/5d-bis 已经在做的——但可升级为**系统性的"置信度可靠性审计"**：在多教师多数据集上，量化"低熵样本到底有多可靠"（用人类难度+正确率+跨模型共识三重标尺）。
- **价值**：直接回应一个顶会论文（GateKD）公开承认的缺口，引用靶子明确。论文价值4。
- **成本**：低（纯分析，已有大部分数据）。
- **判断**：✅ **并入 D1 主线**，作为"我们验证了 GateKD 假设"的核心论证。

### 🆕 D8：黑盒教师的诊断（经济4/论文3）
- **来源**：GateKD 是白盒（需隐状态+注意力），自承不适用 API-only 黑盒教师。
- **我们做**：我们的方法**只需要输出 logprobs**（黑盒可得），不需要隐状态。天然适用 API 教师（GPT/Claude/Gemini）。
- **价值**：实用差异——"能诊断你买不到权重的闭源教师"。经济价值高（很多人只能用API教师）。
- **成本**：中（需调用API教师生成logprobs；但OpenAI/部分API给top-k logprobs）。
- **判断**：⚠️ 作为 D1 的一个**适用性卖点**写进论文（"black-box applicable"），不必单独立项。

### 🆕 D9：跨域蒸馏的可蒸馏性（经济3/论文3.5）
- **来源**：Apple 明确把"教师在源域、学生在目标域"的跨域蒸馏列为未做的未来工作。
- **我们做**：我们已有教师在中文(CMExam)和英文(MMLU/MedQA)的差异数据——可研究"教师在A域可信、到B域是否还可信"（教师可靠性的域迁移）。
- **价值**：填 Apple 的 future work，且我们有现成跨语言数据。
- **成本**：中（已有部分数据，需补分析）。
- **判断**：⚠️ 候选，作为 D1 的一个扩展实验（"教师可靠性是否跨域稳定"），不单独立项。

### 🆕 D10：difficulty(难度) vs disagreement(分歧) 的区分（经济2/论文4）
- **来源**：2508.08204 用"群体分歧"，我们用"专家难度"——这两个概念**没人系统区分过**。
- **我们做**：证明"专家难度"和"标注分歧"是**不同的信号**，且教师熵对哪个对齐更好。这是一个有理论味道的细分贡献。
- **价值**：论文价值高（概念辨析+新发现），但经济价值低（纯学术）。
- **成本**：低（若CMExam有多标注者分歧数据则能做；否则需找带分歧标注的数据）。
- **判断**：✅ 若数据允许，作为 D1 的**理论深化点**（区分难度vs分歧），提升论文档次。
