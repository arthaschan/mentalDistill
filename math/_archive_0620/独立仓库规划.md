# 独立仓库规划：把几何蒸馏研究从 mentalDistill 分离

> 日期：2026-06-20
> 目标：实验完工后，把本数学科研（几何样本筛选蒸馏）独立成一个干净、可复现、可发表配套的新仓库，
> 不再依赖原毕业论文项目 mentalDistill 的庞大历史。
> 本文给出新仓库的目录结构、要搬迁的文件清单、路径改动点、迁移步骤。

---

## 1. 为什么要独立

- 当前研究对毕业论文项目的依赖已很少：训练器自包含，数据只用 CMExam，代码集中在 `research/distillability/`。
- 原 mentalDistill 有 21 个实验模块 + 大量历史，体积大、与本研究无关，不适合作为论文配套仓库。
- 独立后：reviewer / 读者 clone 一个干净仓库就能复现，不被无关模块干扰。

## 4. 路径改动点（搬迁后需修改）

独立后目录层级变了，以下硬编码路径要改：

1. **`common_env.sh`**：原假设 `REBUILD_ROOT=ROOT_DIR/..` 且 shared 在 `REBUILD_ROOT/shared`。
   新结构改为指向 `src/`。
2. **`run_phase2_distill.sh` / `run_medqa_distill.sh`**：
   - `REPO_ROOT`、`DATA15="$REPO_ROOT/15_fulldata_resplit/data"` → 改成 `data/cmexam`。
   - `SHARED_DIR`、`STAGE1` 路径 → 指向 `src/`。
3. **各 .py 脚本里的 `REPO`/路径推导**（如 h1_baseline_comparison.py 的 `DIST` 路径）→ 按新结构调整。
4. **教师 logprobs 路径**：`teacher_labels/` 的位置统一。

> 建议：搬迁后做一个最小冒烟测试（1 教师 1 seed）确认路径全部跑通，再补全。

## 5. 迁移步骤（建议顺序，git 操作你来）

1. 新建空仓库 `geometric-distill-denoising`。
2. 按第 2 节结构建目录，复制第 3 节文件（用 `cp`，不用 git mv，因为是新仓库）。
3. 改第 4 节的路径（最容易出错的一步，逐个脚本改 + 冒烟测试）。
4. 写新仓库的 `.gitignore`（排除 models/ data_ext/ runs/ outputs/ *_logprobs.jsonl）。
5. 写新仓库的英文 README（论文配套，可基于现有中文 README 改）。
6. 冒烟测试：干净环境 clone → 下 1 个教师 → 跑 1 seed 蒸馏 → 确认出结果。
7. 首次 commit + push。
