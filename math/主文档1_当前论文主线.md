## 1. 一句话定位
> 在知识蒸馏场景，用「专家难度等级 + 跨模型共识」双外部金标准，**验证**（而非假设）教师输出不确定性(熵)对应**客观知识难度**，并排除表面文字artifact；据此提供 training-free、label-free、黑盒可用的教师知识缺陷诊断 + 选择性蒸馏，在中文医学全科MCQ(CMExam)上实证。

**数据规模**：CMExam 全量重分割 4608 训练 / 991 测试，每教师约 4600 题真实 logprobs（样本级结论统计充分；教师 N=6 偏小，教师级结论只作趋势）。

## 2. 核心发现（已验证，扎实）
| 编号 | 结论 | 关键数字 |
|---|---|---|
| H4 | 强教师内部用熵定位"在猜"的题 | Qwen32B低可信档err 26.3% vs 高可信2.3%；GLM 42.5% vs 0.7%；6教师4–60× |
| 5c | 纯熵≈训练分类器(label-free) | GLM纯熵 42.7% vs 0.6%；几何logdet_g无独立贡献(AUC<0.27) |
| 5d | 不可信↔外部金标准 | 人类难度 ρ≈0.25–0.35(p<1e-27)；跨模型共识 ρ=0.354(p=1e-134) |
| 5d-bis | 排除表面artifact | 题长/否定词/多步词 ρ≈0 |
| D-b | 暗知识价值随教师强弱而变(新机制) | 高熵样本暗知识命中：强教师Qwen32B 66.7% vs 弱教师Phi4 34.8% |

**跨模型共识的难度梯度**：难度1的题平均仅 0.98 个模型答错，难度5的题 3.45 个答错——单调上升，坐实"共识错误=客观难度"。

**几何可预测性 ∝ 教师质量（统一机制）**：用GT-无关几何特征预测"教师该题对错"的 AUC 随教师变强单调升高——Llama70B 0.66 / Phi-4 0.745 / Qwen14B 0.856 / Qwen32B 0.870 / GLM 0.879。强教师犯错时分布必然"露馅"（熵升、峰降）几何可分；弱教师的错误与其"自信错误"几何上不可分。**这解释了为何弱教师噪声难以过滤**，本质起作用的是熵而非几何包装。

**D-b 暗知识完整趋势**（命中率=教师top1答错时次高概率正好是正确答案的比例，随机基线~25%）：高熵−低熵命中差 Qwen32B +34.4 / Qwen14B +37.4 / GLM +14.3 / Yi −1.2 / Gemma −8.0 / Phi −11.6。**统一价值**：解释了为何选择性筛选只对弱教师有效——弱教师高熵暗知识是噪声(剔除有益)，强教师高熵暗知识仍指向正确(剔除有害)。

## 3. 诚实负结果（每个都让论点更精确）
- **H1/H2 证伪**：教师级"几何预测可蒸馏性"失败；5指标(DI/acc/熵/LEEP/LogME)排序全共线 ρ=−0.80，几何=熵=准确率代理，无独立价值。
- **结构特征冗余**（任务C负结果）：新增8个"混淆模式"结构特征(参与比/碰撞熵/top2质量/基尼等)联合后增益≈0甚至轻微为负。说明单教师分布的几何信息有天花板，特征工程到此为止；要突破须靠跨样本/跨教师/难度信息。
- **N=6 蒸馏趋势**(geom−random)：Gemma +2.22 / Phi +0.81 / Yi +0.60 / GLM +0.14 / Qwen14B −0.78 / Qwen32B −0.54。→ 选择性蒸馏增益随教师变强而递减，强教师为负。
- **领域融合**：上界 +0.00pp（Qwen32B 全7学科最强，无互补；英文+国外强模型阵容下或可复活，待验证）。

## 4. 选择性蒸馏因果验证（任务A，3-seed，Llama70B 弱教师→Qwen14B 学生）
- 几何分数**不看GT**即选出教师正确率更高的子集：geom_top50 64.57% vs random 53.51%（+11pp），证明是有效的可信度代理。
- 学生测试准确率：geom_top50 **+2.19pp** vs 全量baseline，**+0.53pp** vs random_top50（方向稳健但效应小）；geom_top50 同时方差最小。
- **诚实拆解**：弱教师上大头增益(+1.65pp)来自"少用噪声KL监督"，几何带来的净额外增益仅约+0.5pp（与std同量级，不能说强证据）。这与"几何可预测性∝教师质量"一致：Llama70B 几何可分性最差(AUC0.66)，几何增益本就该最小。

## 6. Prior-art 与真实 delta（三轮全文精读后）
| 竞品 | 占了什么 | 我们的差异 |
|---|---|---|
| Apple Distillation Scaling Laws (2502.08606) | 缩放定律(只预测loss，不做下游正确率/难度/跨域) | 我们预测下游MCQ正确率+难度感知+医学 |
| GateKD (2605.13136) | 置信门控选择性蒸馏（白盒，需隐状态+注意力） | 它**假设**熵=可靠(作者自承可能miscalibrated)；我们**验证**它(双金标准)；我们黑盒可用 |
| Trust the Uncertain Teacher / CUD (2602.12687) | 校准教师分布(改软标签) | 我们检测+剔除不可信样本(选数据)+外部难度验证；可作支撑引用 |
| Uncertainty Propagation in KD (2601.18909) | 不确定性传播的方差视角(理论) | 不撞，背景引用 |
| 2508.08204 | 不确定性↔人类**群体分歧** | 我们用专家**难度等级**(非分歧)+跨模型共识+蒸馏场景 |
| JCST综述(s11390-026-6426-z) | 校准领域综述(非竞品) | 我们related work骨架 |

**真实delta**：没有任何一篇同时具备「教师熵 + 专家难度&跨模型共识双验证 + 蒸馏诊断 + 医学MCQ」。
**诚实收窄**：不能宣称首次发现"不确定=人类难度"这个一般规律（2508.08204 已在通用任务上做，human-aligned uncertainty 是活跃子领域）；我们的 delta 是把它**首次系统应用到蒸馏教师诊断 + 专家难度&跨模型共识双验证 + 医学 + 工具化**。属应用型+实证型贡献，非理论首创。
**黑盒卖点(D8)**：方法只需输出 logprobs（黑盒可得），不需隐状态，天然适用 API 闭源教师（GPT/Claude/Gemini），是 GateKD 等白盒方法做不到的实用差异。

**related work 骨架（用 JCST 综述，张敏灵 东南大学）**：不确定性校准分四范式（训练时正则/事后调整/贝叶斯集成/混合）+ 新挑战（OOD/生成/多模态/人机协作）+ LLM三问；顺其引文[115][116][119]补 prior-art。经精读核对，综述里的"distillation/difficulty/human-aligned"均为别的含义，未占我们空白。

## 7. 诚实定级与差距
- **级别**：中等会议(EMNLP/NAACL findings、AAAI)/中科院二三区/医学AI期刊(JBHI/AIM)/优秀硕士论文。**非顶会**(无理论首创)。

## 8. reviewer 风险与回应
- "跨模型共识会不会是 shared error？"→ 6教师跨6公司异构(multi-family配置)，非同源盲点。
- "用熵找不可信≠置信度校准？"→ 校准只问"自信度准不准"；我们用人类难度+跨模型共识证明"不确定=客观难点"，有外部金标准。
- "只在中文医学/MCQ成立？"→ 跨数据集(MedQA)验证中；诚实声明适用范围(封闭候选MCQ、教师可靠性任务相关)。
- **prior-art 检索局限（诚实边界）**：arXiv 关键词匹配对本课题命中质量差，体检工具方向 Google Scholar/Semantic Scholar 检索尚不充分；投稿前须人工补查 "uncertainty calibration = human difficulty" 是否被精确占据，补齐前不宣称"完全新颖"。
- **方法学教训**：软标签文件须先确认未被 GT 锚定（argmax==GT 比例应=教师真实准确率而非100%），否则无法研究"教师答错时的几何"。
