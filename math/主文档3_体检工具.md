# 📘 主文档3：体检工具（scan_teacher.py）相关

> 浓缩主文档（自包含）| 更新 2026-06-20 | 整合工具的价值评估/设计/验证/开源方案。

---

## 1. 工具是什么
`scan_teacher.py` —— 教师可蒸馏性体检工具。输入教师logprobs，输出：
- label-free 检测"不可信区"(高熵=在猜)
- 难度自证(不确定区↔人类难度/跨模型共识)
- 领域地图(各学科可靠性)
- 选择性蒸馏数据(剔除不可信样本)
特性：training-free、label-free、黑盒可用(只需logprobs)。

## 2. 价值阶梯（诚实区分：什么形态有价值）
| 工具形态 | 价值 | 判断 |
|---|---|---|
| 只按熵过滤样本再蒸馏 | 低 | 已有(confidence-based filtering)，换皮 |
| +输出"教师在哪些领域/难度不可信"体检报告 | 中 | 可解释、可指导 |
| +用独立金标准(人类难度/跨模型共识)自证不可信是真难点 | **高** | 别人没有的独特资产(5d已验证) |
| +对未参与研究的新模型一键体检并复现验证 | **高+泛化背书** | 证明非过拟合 |

**结论**：值得做，但必须做到第3、4行形态，不能停在第1行(否则=换皮)。

## 3. 价值评估
### 论文价值：中等偏上
- 工具**不是**论文核心；**工具+背后科学发现(不确定区=客观难点+外部验证)才是**。
- 正确定位：写成"我们发现X(不确定=客观难点，training-free可检测)，并提供工具使其可复现、可推广到新模型"——工具是 reproducible artifact，是 strengthen，不是 main claim。
- 层级：工具+现有发现→中等会议/findings；加泛化验证→冲中等期刊；加选择性蒸馏多数据集增益→四件套故事完整。
- 天花板：核心是熵(非全新)+几何无独立贡献(已诚实承认)，很难冲顶刊。

### 商业价值：有限但真实
- 不是能独立卖钱的产品，是"蒸馏/模型选型流程里的一个降本环节"(训练前省一轮蒸馏)。

### 护城河（为什么不是换皮）
置信度校准方法**不验证"不确定=客观难"**——这是我们工具独有的(靠5d外部验证)。三个独特资产：(1)5d难度/共识自证；(2)5c label-free纯熵即可定位；(3)B领域级地图(人能看懂的报告)。

### 诚实风险/边界
- 审稿人会说"selective prediction 老问题"→ 必须靠 5d 外部验证差异化。
- 难度相关中等(ρ≈0.35)，不能宣称"精准检测"，报告须给相关系数+置信区间。
- 工具命名/宣传**不应**主打"信息几何"(几何无独立贡献)，应主打"不确定性+外部验证的知识缺陷诊断"。
- 选择性蒸馏增益弱教师明显、强教师小，报告须按教师强弱诚实标注适用场景。

## 4. 工具设计（scan_teacher）
**输入**：一个教师模型路径(本地HF) + 一个带GT的探针数据集(可选带难度/领域标签如CMExam)。
**输出**(体检报告 JSON + 可读 markdown)：①整体可蒸馏性(准确率/平均熵) ②样本级不可信标记(label-free可信度分) ③领域地图(按领域/难度的准确率与不可信比例) ④自证模块(若有难度标签，自动算"不可信vs难度"相关) ⑤选择性蒸馏数据集(已剔除不可信样本的训练集)。
**复用现有零件**(不重写)：logprobs生成`shared/generate_teacher_labels_local_logprobs.py` + 熵/几何打分`expA_labelfree.py` + 领域地图`exp_AB_strong_teacher_map.py` + 难度自证`cross_validate_difficulty.py` + 选择性蒸馏数据`build_geometry_filtered_dataset.py`。工具=把这5个零件串成"喂模型→出报告→出蒸馏数据"流水线。

## 5. 外部验证与泛化（强化 external validity）
- 已做：6教师上难度自证(ρ0.35)+跨模型共识(ρ0.354)+排除文字artifact。
- 进行中：对未参与研究的新模型(Qwen2.5-7B)一键体检 → 泛化验证(后台排队)。审稿人会问"会不会只对这6个成立"，新模型若同样定位不可信区且与人类难度正相关→证明工具泛化、规律普适=external validation强证据。
- P3延伸：跨域稳定性(已证AUC跨4域0.70-0.88)。
