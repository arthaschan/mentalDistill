# 复现指南

本文档让你从零复现 mentalDistill 的全部实验。按顺序执行即可。

---

## 0. 环境搭建

```bash
git clone https://github.com/arthaschan/mentalDistill.git
cd mentalDistill

# 建议用 conda 新建环境（Python 3.10+）
conda create -n mentaldistill python=3.10 -y
conda activate mentaldistill
pip install -r requirements.txt

# 配置环境变量
cp setup.env.example setup.env
#   编辑 setup.env：把 EASYEDIT_PY 改成你的 python 路径（which python）
source setup.env
```

硬件：单张 GPU。14B 学生 bf16 训练约需 28GB+ 显存；32B/34B 教师推理约需 60-70GB。
实验在 NVIDIA H100 NVL 95GB 上完成。显存不足时可只复现弱教师小模型部分。

## 1. 模型下载

所有模型从 HuggingFace 下载，存到 `models/` 下（该目录已被 .gitignore 排除）。
推荐用 `hf` CLI（`pip install -U huggingface_hub`）；国内网络慢可设镜像 `export HF_ENDPOINT=https://hf-mirror.com`。

| 角色 | 模型 | HuggingFace repo | 存放路径 |
|---|---|---|---|
| 学生 | Qwen2.5-14B-Instruct | `Qwen/Qwen2.5-14B-Instruct` | `models/Qwen2.5-14B-Instruct` |
| 教师(强) | Qwen2.5-32B-Instruct | `Qwen/Qwen2.5-32B-Instruct` | `models/Qwen2.5-32B-Instruct` |
| 教师(强) | Qwen2.5-14B-Instruct | `Qwen/Qwen2.5-14B-Instruct` | （同学生） |
| 教师(强) | GLM-4-32B-0414 | `zai-org/GLM-4-32B-0414` | `models/GLM-4-32B-0414` |
| 教师(中) | Yi-1.5-34B-Chat | `01-ai/Yi-1.5-34B-Chat` | `models/Yi-1.5-34B-Chat` |
| 教师(弱) | gemma-2-27b-it | `google/gemma-2-27b-it` | `models/gemma-2-27b-it` |
| 教师(弱) | phi-4 | `microsoft/phi-4` | `models/phi-4` |

下载示例：
```bash
hf download Qwen/Qwen2.5-14B-Instruct --local-dir models/Qwen2.5-14B-Instruct
hf download microsoft/phi-4 --local-dir models/phi-4
# gemma 需先在 HF 网页同意许可，再用 token：
hf download google/gemma-2-27b-it --local-dir models/gemma-2-27b-it --token <你的HF_token>
```

> 注：gemma-2 的 chat 模板不支持 system role，本仓库的 logprobs 生成脚本已自动处理
> （检测到不支持时把 system 提示并入 user turn）。

## 2. 数据准备

### 2.1 CMExam（主数据集，已含在仓库）
- 位置：`15_fulldata_resplit/data/{train,val,test}.jsonl`
- 来源：CMExam（中文全科医学考试 MCQ benchmark，7 大学科：临床/公卫/口腔/药学/中药/中西医/中医）。
- **格式差异说明**：
  - 原始 CMExam 为 CSV（字段：Question, Options, Answer, Explanation, Disease Group,
    Area of Competency, Clinical Department, Medical Discipline, Difficulty level）。
  - 本研究转为 JSONL，每行一个对象：`{"Question": str, "Options": {"A":..,"B":..,...}, "Answer": "A".."E", ...}`，
    并做了 train/val/test 切分。原始 CSV 见 `shared/cmexam_full.csv`。

### 2.2 MMLU / MedQA（跨数据集验证，用脚本下载）
公开数据集，不随仓库提交。用适配器脚本一键下载并转成统一 JSONL 格式：

```bash
export HF_HUB_ENABLE_HF_TRANSFER=0      # 用官方源直连
# MMLU 医学子集（7 学科，4 选）
python research/distillability/scripts/load_mcq_dataset.py --dataset mmlu_med  --out_dir data_ext/mmlu_med
# MMLU 全科（57 学科，跨域）
python research/distillability/scripts/load_mcq_dataset.py --dataset mmlu_full --out_dir data_ext/mmlu_full
# MedQA USMLE（英文执业考，4 选）
python research/distillability/scripts/load_mcq_dataset.py --dataset medqa     --out_dir data_ext/medqa
```
- 输出：`data_ext/<数据集>/{train,val,test}.jsonl` + `meta.json`。
- 数据来自 HuggingFace：`cais/mmlu`、`GBaker/MedQA-USMLE-4-options`。

## 3. 实验清单（按依赖顺序）

每个实验：**目的 / 启动命令 / 产出 / 预期**。脚本逐一说明见 `实验脚本索引.md`（同在 math/ 下）。

### 实验 1：生成教师 logprobs（所有后续实验的基础）
- 目的：让每个教师在 CMExam train 上输出对 A-E 的真实概率分布（软标签）。
- 命令（每个教师跑一次，以 phi-4 为例）：
```bash
python shared/generate_teacher_labels_local_logprobs.py \
  --model_path models/phi-4 \
  --dataset 15_fulldata_resplit/data/train.jsonl \
  --output research/distillability/teacher_labels/phi4_train_logprobs.jsonl \
  --gt_field Answer --resume
```
- 产出：`research/distillability/teacher_labels/<teacher>_train_logprobs.jsonl`
- 预期：日志末尾打印 Teacher Acc（如 phi-4 在 CMExam ≈ 54.5%）。

### 实验 2：教师几何分析 + 可蒸馏性打分
- 目的：从 logprobs 算几何特征（logdet_g、单纯形边界距离、熵、margin、peak）、几何 AUC、可蒸馏性指数 DI。
- 命令：
```bash
python research/distillability/sample_geometry.py --teachers "Phi4:research/distillability/teacher_labels/phi4_train_logprobs.jsonl"
python research/distillability/teacher_distillability_score.py \
  --teachers "Phi4:research/distillability/teacher_labels/phi4_train_logprobs.jsonl" [更多教师...] \
  --output research/distillability/outputs/teacher_distillability_scores_N7.json
```
- 产出：`outputs/sample_geometry_<teacher>.csv`、`outputs/teacher_distillability_scores_N7.json`

### 实验 3：迁移性指标 LEEP / LogME（对标基线）
- 目的：算迁移学习社区标准指标，作为"教师级预测"的对标。
- 命令：`python research/distillability/scripts/transferability_scores.py`
- 自检：`python research/distillability/scripts/transferability_scores.py --selftest`
- 产出：`outputs/transferability_scores.json`

### 实验 4：几何筛选 3-seed 蒸馏（核心实验）
- 目的：验证"几何筛选样本"相对"随机筛选"是否提升弱教师蒸馏。三臂：baseline_all / geom_top50 / random_top50。
- 命令（每教师 3 个 seed）：
```bash
for s in 42 8 11; do SEED=$s bash research/distillability/scripts/run_phase2_distill.sh phi4; done
```
- 产出：`research/distillability/runs/phase2_<teacher>/logs/<arm>_seed<s>.log`（grep `[TEST-BEST]` 取准确率）
- 预期：弱教师上 geom_top50 − random_top50 > 0（如 Gemma +2.22pp、Phi-4 +0.81pp）。

### 实验 5：H1 指标家族对比（分水岭分析）
- 目的：比较 5 个 training-free 指标（DI/准确率/熵/LEEP/LogME）预测蒸馏增益的排序相关。
- 命令：`python research/distillability/scripts/h1_baseline_comparison.py`
- 产出：`outputs/h1_baseline_comparison.json`
- 结论：几何无独立预测力，且增益与教师质量负相关（详见 `math/方向B_实验报告_滚动更新.md` 第 3、6 节）。

### 实验 6：跨数据集验证（MedQA）
- 目的：验证"几何去噪增益"是否在 CMExam 之外（英文 MedQA）也成立。
- 命令：`bash research/distillability/scripts/run_medqa_distill.sh Phi4 models/phi-4`（需先下载 MedQA，见 2.2）
- 产出：`research/distillability/runs/medqa_<teacher>/`
- 汇总：`python research/distillability/scripts/summarize_medqa.py`

## 5. 复现注意事项

- 所有蒸馏用固定随机种子（42/8/11）并加 `--deterministic`，3-seed 取均值±std。
- 几何筛选阈值默认 keep_frac=0.5（top-50%）。
- 单 GPU 时教师推理与学生训练**不能并行**（会 OOM），需顺序执行。
- 教师可靠性是**任务相关**的：同一教师在不同数据集准确率差异很大（如 phi-4 中文 54.5% vs 英文 78-88%），
  因此可蒸馏性预测须在目标任务的校准集上测，不能跨域外推。
