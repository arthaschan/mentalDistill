# 实验脚本索引

`research/distillability/scripts/` 下所有脚本的作用、用法、依赖。
（`.sh` 编排脚本 + `.py` 分析脚本）

---

## 核心实验脚本

| 脚本 | 作用 | 用法 | 依赖 |
|---|---|---|---|
| `../sample_geometry.py` | 算教师每样本几何特征 + 几何AUC | `python sample_geometry.py --teachers "Label:logprobs.jsonl"` | 教师 logprobs |
| `../teacher_distillability_score.py` | 算可蒸馏性指数 DI（z(acc)+z(geom_auc)+z(可分度)） | `--teachers "L:path" --output xxx.json` | 教师 logprobs |
| `../build_geometry_filtered_dataset.py` | 构建 baseline/geom/random 三臂数据集 | `--input head.jsonl --outdir dir --keep_frac 0.5` | head-distill 数据 |
| `transferability_scores.py` | LEEP/LogME 迁移性指标（对标基线） | `python transferability_scores.py [--selftest]` | 教师 logprobs |
| `h1_baseline_comparison.py` | 5指标家族 vs 真实蒸馏增益排序相关 | `python h1_baseline_comparison.py` | 蒸馏 runs + 上述输出 |
| `e2_cross_dataset.py` | 跨数据集指标一致性分析 | `python e2_cross_dataset.py` | teacher_labels_ext/ |

## 蒸馏编排脚本（.sh）

| 脚本 | 作用 | 用法 |
|---|---|---|
| `run_phase2_distill.sh` | 单教师 CMExam 三臂蒸馏（1 个 seed） | `SEED=42 bash run_phase2_distill.sh <teacher>` |
| `run_taskA_train.sh` | 早期 Task-A 三臂蒸馏（Llama70B 教师） | `SEED=42 bash run_taskA_train.sh` |
| `run_medqa_distill.sh` | MedQA 跨数据集蒸馏（英文 prompt） | `SEED=42 bash run_medqa_distill.sh <teacher> <model_path>` |
| `task2_extend_teachers.sh` | 批量补 Qwen14B/32B 蒸馏（扩 H1 的 N） | `bash task2_extend_teachers.sh` |
| `task3_medqa_relay.sh` | 等任务2完成后自动跑 MedQA 全部教师 | `bash task3_medqa_relay.sh` |
| `summarize_medqa.py` | 汇总 MedQA 三臂结果 | `python summarize_medqa.py` |

## 数据/模型下载脚本

| 脚本 | 作用 | 用法 |
|---|---|---|
| `load_mcq_dataset.py` | 下载并统一 MMLU/MedQA/CMExam 格式 | `python load_mcq_dataset.py --dataset mmlu_med --out_dir data_ext/mmlu_med` |
| `download_phase2_teachers.py` | 批量下载 Phase-2 教师模型 | 见脚本内注释 |
| `download_phase2_hf.py` | HuggingFace 下载（官方源） | 见脚本内注释 |
| `download_gemma_token.py` | 带 token 下载 gemma（需许可） | `HF_TOKEN=xxx python download_gemma_token.py` |

## 辅助脚本

| 脚本 | 作用 |
|---|---|
| `precheck_option_tokens.py` | 检查模型的 A-E option token 映射是否正确（蒸馏前预检） |
| `litsearch.py` | 文献查重检索（arXiv + Semantic Scholar）；`round2` 参数跑第二轮 |
| `phase2_predict.py` | Phase-2 预注册预测生成 |

## 共享组件（`shared/`）

| 文件 | 作用 |
|---|---|
| `generate_teacher_labels_local_logprobs.py` | 从本地模型生成教师 A-E 软标签（含 gemma system-role 兼容处理） |
| `train_choice_head_distill.py` | Choice-Head 蒸馏训练器（学生）。环境变量 `DISTILL_PROMPT_LANG=en` 切英文 prompt |
| `build_selective_distill_dataset.py` | 从真实 logprobs 构建 head-distill 数据集 |
| `common_env.sh` | 路径/python 解析的公共环境函数 |
