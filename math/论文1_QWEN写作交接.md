## 1. 论文定位（标题方向 + 一句话贡献）

候选定位（按导师偏好"诚实、可复现、有外部效度"排序，推荐第1个）：

1. **【推荐】外部验证的教师知识缺陷诊断**：在知识蒸馏场景，用"专家难度等级 + 跨模型共识"双外部标准答案，**验证（而非假设）**教师输出不确定性（熵）对应**客观知识难度**，并排除表面文字 artifact；据此提供 training-free、label-free、黑盒（仅需 logprobs）可用的教师知识缺陷诊断，在中文医学全科 MCQ（CMExam）上实证，并跨英文医学/通用域验证稳定性。

2. 备选（更保守的负结果版）：多种 training-free 指标都无法超越"教师准确率"预测可蒸馏性，但其中的熵信号能在单教师内部精准定位"在猜"的子集，且该信号有外部效度。

**真实 delta（必须如实写，不可夸大）**：没有任何一篇 prior-art 同时具备「教师熵 + 专家难度&跨模型共识双验证 + 蒸馏诊断 + 医学 MCQ」。但**不能宣称首次发现"不确定=人类难度"这个一般规律**（2508.08204 已在通用任务上做，human-aligned uncertainty 是活跃子领域）。我们的贡献是**应用型 + 实证型**：把它首次系统应用到蒸馏教师诊断 + 专家难度&跨模型共识双验证 + 医学 + 工具化。**非理论首创**。

## 3. 核心发现（已验证，这是论文的主体；数字逐一可查）

### 3.1 五个核心结论表

| 编号 | 结论 | 关键数字（源：方向B报告 / outputs JSON） |
|---|---|---|
| H4 | 强教师内部用熵定位"在猜"的题 | Qwen32B 低可信档 err 26.3% vs 高可信 2.3%（11×）；GLM 42.5% vs 0.7%（60×）；6 教师跨度 4–60× |
| 5c | 纯熵 ≈ 训练分类器（真正 label-free） | GLM 纯熵 42.7%/0.6% ≈ 训练版 42.5%/0.7%；entropy/margin/peak 三写法 AUC 同到小数后两位 |
| 5d | 不可信 ↔ 外部标准答案 | 教师熵 vs 人类难度 6教师全正相关，均值 ρ≈0.246，全 p<1e-27；跨模型共识 vs 人类难度 ρ=0.354 (p=1.4e-134) |
| 5d-bis | 排除表面文字 artifact（负结果，有价值） | 题长 ρ=−0.030 / 否定词 ρ=−0.003 / 多步词 ρ=−0.026；含否定词题错误率 25.5% vs 普通 25.3%（无差异） |
| D-b | 暗知识价值随教师强弱而变（新机制） | 高熵−低熵"暗知识命中"差：Qwen32B +34.4 / Qwen14B +37.4 / GLM +14.3 / Yi −1.2 / Gemma −8.0 / Phi −11.6 |

### 3.2 跨模型共识的难度梯度（5d 的最强证据，要单独成段）
"几个模型一起答错"随人类难度单调上升：难度1 → 0.98 个模型错；难度3 → 2.01；难度5 → 3.45（ρ=0.341, p=6e-125）。两个完全独立信号（模型熵 / 人类标注）相互印证。

### 3.3 几何可预测性 ∝ 教师质量（统一机制，可作 discussion）
用 GT-无关几何特征预测"教师该题对错"的 AUC 随教师变强单调升高：Llama70B 0.66 / Phi4 0.745 / Qwen14B 0.856 / Qwen32B 0.870 / GLM 0.879。解释了为何弱教师噪声难过滤——强教师犯错时分布必然"露馅"几何可分，弱教师自信错误几何不可分。**真正起作用的是熵，不是复杂几何。**

### 3.4 P3 跨域稳定性（本论文的"泛化"章节，6教师×4域已完成）
熵检测 AUC 跨 4 域（CMExam中 / MedQA英医 / MMLU-med英医 / MMLU-full英通）：Qwen32B 0.760–0.875；Qwen14B 0.786–0.858；GLM32B 0.782–0.891；Yi34B 0.698–0.821；Gemma27B 0.758–0.876；Phi4 0.747–0.851。**24个数据点全部 0.70–0.89，无一掉到随机。** 跨模型共识↔单教师熵 ρ：CMExam +0.681 / MedQA +0.699 / MMLU-med +0.706 / MMLU-full +0.758。
> 注：P3 既可作本论文的泛化章节，也是独立"论文2"的核心。与用户确认——本交接里**P3 作为论文1的跨域泛化证据**收入；若用户要把 P3 独立成篇，则论文1只引用"跨域稳定（详见后续工作）"一句即可。**写作时按用户当场指示。**

## 4. 诚实负结果（每个都让论点更精确，必须写进论文，不许藏）

- **H1/H2 证伪**：教师级"几何预测可蒸馏性"失败；5 指标（DI/acc/熵/LEEP/LogME）排序全共线 ρ=−0.80（N=4，p=0.20 不显著，只作趋势），几何=熵=准确率代理，**无独立价值**。
- **相关是负的**：教师越强，蒸馏增益越小——强教师学生 baseline 已近天花板，可提升空间小。原 H1"高 DI→高增益"方向被推翻。
- **结构特征冗余（任务C负结果）**：新增8个"混淆模式"结构特征联合后增益≈0甚至轻微为负。特征工程到此为止。
- **neg_logdet_g 反向**：流形体积元近似 AUC 全 <0.27，与熵负相关、无独立贡献——**削弱"复杂信息几何"叙事**，论文应收敛为"简单一阶集中度指标（熵）够用"。
- **领域融合否决**：领域路由融合 vs 单一最强教师 = **+0.00pp**（Qwen32B 全7学科最强，无互补）；oracle 上界 +7.94pp 但 training-free 不可达。结论：体检工具价值在"单教师内部样本筛选"，不在"跨教师融合"。
- **选择性蒸馏增益小且依赖教师强弱**：geom−random 增益 Gemma +2.22 / Phi +0.81 / Yi +0.60 / GLM +0.14 / Qwen14B −0.78 / Qwen32B −0.54。弱教师有去噪空间，强教师筛选无益甚至有害。MedQA 跨数据集复现同向（Phi4 +0.94 / Yi34B +1.44 / Qwen32B +0.13）。

## 8. 诚实边界 / reviewer 风险（导师审稿严——必须主动列、逐条回应，不许回避）

- "跨模型共识会不会是 shared error？" → 6 教师跨 6 公司异构，非同源盲点（§5）。
- "用熵找不可信 ≠ 置信度校准？" → 校准只问"自信度准不准"；我们用人类难度+跨模型共识证明"不确定=客观难点"，有外部标准答案。
- "只在中文医学/MCQ 成立？" → P3 跨 4 域验证（中→英、医学→通用）；但诚实声明适用范围（封闭候选 MCQ、教师可靠性任务相关）。
- "ρ≈0.25–0.35 是中等相关不是强相关" → 如实报告，熵与难度对应但不完美：不可信里既有真难点也有部分模型特异不确定。**不许夸大为"完美对应"。**
- "教师可靠性是任务相关的" → Phi4 英文 78–88% 但中文 CMExam 仅 54.5%——可蒸馏性预测必须在目标任务校准集上测，不能跨语言外推。这是约束也是诚实边界。
- "N=6 教师偏小" → 样本级结论（每教师约4600题 logprobs）统计充分；教师级结论只作趋势，已声明。
- **prior-art 检索局限**：arXiv 关键词匹配对本课题命中质量差，Google Scholar/Semantic Scholar 检索尚不充分；投稿前须人工补查"uncertainty calibration = human difficulty"是否被精确占据，补齐前不宣称"完全新颖"。
- **方法学教训（写进 setup 脚注）**：软标签文件须先确认未被 GT 锚定（argmax==GT 比例应=教师真实准确率而非100%），否则无法研究"教师答错时的几何"。
