# 中文牙科子集数据集 · 全网搜索结果

> 检索时间：2026-08-17。方法：HuggingFace API + DuckDuckGo + arXiv 全文，实测可访问性（非臆测）。
> 目标：为"中文牙科 4% 差组合"找更多可用的牙科 MCQ 数据。

---

## 一、头条发现：DentalBench / DentalQA（最对口）

- **论文**：arXiv 2508.20416（2025-08）《DentalBench: Benchmarking and Advancing LLMs Capability for Bilingual Dentistry Understanding》
- **项目页**：GitHub `josa6f/DentalBench`
- **核心资产 DentalQA**：
  - **中英双语**牙科问答基准，**36,597 题**，覆盖 **16 个牙科子领域**。
  - **4 类任务**：
    1. **MCQ** 单选 —— **英文 4 选项（A-D）/ 中文 5 选项（A-E）**，考事实记忆。← 与本项目 A-E 格式完全一致
    2. MAQ 多选
    3. OEQ 开放式问答（临床场景）
    4. DEF 术语定义题
  - 另附 **DentalCorpus**（3.37 亿 token 牙科语料，供 SFT/RAG）。
- **对我们的价值**：`DentalQA-ZH` 的中文 MCQ 部分（5 选项）可直接作为"中文牙科"的扩充数据源，比现有 CMExam 口腔医学子集（~830 题）大一个量级。
- **待办**：DentalQA 的原始下载地址未在论文 HTML 直接暴露，需从 GitHub 项目页 / 论文 Data Availability 段 / 作者处进一步确认托管位置（HF 或 Zenodo）。

## 四、结论与建议

1. **最优增量 = DentalQA-ZH 的 MCQ 子集**：中英双语、5 选项单选、16 牙科子领域，是最对口的"中文牙科"扩充源。
2. **次优 = CMExam 口腔医学扩充**：现有 csv 里口腔医学单选约 830 题，可确认是否还有未纳入的牙科题（如多选转单选、无答案题）。
3. **M3Exam / CMB / MLEC-QA** 可作第三梯队，需要从全科里筛"口腔"关键词，投入产出比低于前两者。
4. 商业题库（口腔执业医师真题 App、DentalDecks 等）多受版权保护，不能程序化抓取，仅作人工参考。

## 五、下载核实结果（2026-08-17 晚）

**DentalQA/DentalBench 目前下载不到，数据未公开。** 核实过程：

1. 论文 PDF 全文（arxiv.org/pdf/2508.20416，7 页）翻遍，**无任何 github/huggingface/zenodo/下载链接**，也没有"数据可用性"声明。
2. 之前搜到的 GitHub `josa6f/DentalBench` 是**假阳性**——那是西班牙一家牙科器械公司官网（卖牙套/美白/义齿），与学术论文无关。
3. HuggingFace 搜 `DentalBench`=0 结果，`DentalQA` 只有无关的论坛爬取数据（jonathankang/dental_QA、ChuGyouk/dentalQA_sample），都不是论文的 DentalQA。
4. ModelScope（中国版 HF）也搜不到。
5. **实测下载了 M3Exam 中文子集**（chiayewken/m3exam，dev 29 题 + test 682 题），内容是中学考试（语文/数学/化学/历史/政治），**不是医学，更无牙科**，不可用。

**结论**：论文 2025-08-28 才发，DentalQA 数据尚未公开。当前全网可下载的中文牙科 MCQ 只有本项目已有的 **CMExam 口腔医学（830 题单选）**。

**后续三条路**：
- A. 给作者发邮件要数据（论文邮箱 `zhuhengchuan1.24@intl.zju.edu.cn`，浙江大学 ZJU-Angelalign 中心）。
- B. 等它公开（论文很新，可能近期上 HF），过段时间重查。
- C. 不纠结新数据，用现有 CMExam 口腔 830 题 + 英文 MedMCQA 牙科继续推进。

## 六、诚实边界

- DentalQA 的准确托管地址（HF/Zenodo）尚未坐实，需进一步确认；题量与任务结构来自论文摘要+正文，可信。
