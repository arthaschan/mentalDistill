# 答辩摘要

## 一句话版本

本文提出了面向牙科五选一选择题的 Choice-Head 两阶段蒸馏框架，在 45 倍参数压缩条件下，使 14B 学生模型在 991 题全量测试集上达到 89.10% 准确率，超过 87.18% 的 DeepSeek-V3 教师。

## 答辩首页版摘要

本研究聚焦牙科智能问答在真实部署中的核心矛盾：高性能模型虽然具备较强医学答题能力，但推理成本高、部署门槛高，难以直接应用于教学演示、标准化考试训练等轻量场景。为解决这一问题，本文以 CMExam 牙科选择题为评测对象，提出了 Choice-Head 两阶段蒸馏框架，将传统全词表蒸馏改写为五个候选选项上的概率分布蒸馏，从而同时兼容黑盒 API 教师与白盒本地教师，并显著降低显存与计算开销。

围绕该方法，本文完成了 21 组系统性实验。结果表明：14B 学生模型在 991 题全量测试集上达到 89.10% 最佳准确率，超过 87.18% 的 DeepSeek-V3 教师；教师质量与蒸馏收益呈倒 U 型关系，较高准确率且保留适度 teacher-GT 分歧的教师更容易提供有效蒸馏信号；真实 logprobs 标签比人工平滑标签保留了更丰富的连续结构信息；异构教师同样能够产生有效蒸馏信号。研究说明，围绕任务决策结构重新设计蒸馏目标，是推动医疗大模型轻量化落地的一条可行路径。

## 口头陈述版摘要

我的论文主要研究一个问题：医疗大语言模型性能很强，但成本太高，能不能把这种能力迁移到更小、可部署的学生模型上。为此，我选择牙科医学选择题作为标准化任务，基于 CMExam 数据集构建了面向牙科五选一任务的评测设置，并提出了 Choice-Head 两阶段蒸馏框架。这个方法的关键点在于，不再蒸馏十几万维的全词表 logits，而是只蒸馏 A、B、C、D、E 五个选项上的概率分布，因此更贴合选择题任务本身，也能兼容 API 教师。

实验上，我完成了 21 组系统性对比。最重要的结果是，Qwen2.5-14B 学生模型在 991 题全量测试集上达到 89.10% 准确率，超过了 87.18% 的 DeepSeek-V3 教师。这说明在合适的训练配置下，学生模型不只是接近教师，甚至有可能超过教师。除此之外，我还发现教师越强不一定越适合蒸馏，教师质量和蒸馏收益之间呈倒 U 型关系；同时，真实 logprobs 标签比人工平滑标签更有信息价值，异构教师也可以提供有效监督。

本文的意义在于说明：当任务形式足够明确时，蒸馏目标可以围绕任务决策结构重新定义，而不必拘泥于通用的大模型训练范式。这一思路不仅适用于牙科选择题，也有希望推广到更广泛的标准化医疗知识评测任务中。

## PPT 可直接摘取的 4 点

1. 研究问题：高性能医疗大模型难以直接低成本部署。
2. 核心方法：提出 Choice-Head 两阶段蒸馏，只蒸馏五个选项上的概率分布。
3. 最佳结果：14B 学生在 991 题测试集上达到 89.10%，超过 87.18% 的教师模型。
4. 核心结论：教师不是越强越好，任务结构对齐的蒸馏目标可以带来更高迁移效率。
