# 答辩当天打开顺序

用途：答辩开始前按顺序打开，减少现场切文件时间。

## A. 开场前固定打开

1. thesis/答辩现场速查版.md
2. thesis/答辩20秒口语稿.md
3. thesis/答辩备查材料清单.md

## B. 数字被追问时打开

1. 03_doubao_choice_head/logs/teacher_eval_report_rerun.json
2. 04_kimi_choice_head/logs/teacher_eval_report_rerun.json
3. 04_kimi_choice_head/data/distill_dataset_report_rerun.txt
4. 16_llama70b_choice_head/README.md

## C. 原理和边界被追问时打开

1. docs/thesis_experiment_report.md
2. docs/multi_teacher_ensemble_plan.md
3. thesis/thesis_v2.md

## D. 现场操作建议

1. 第一屏只留 thesis/答辩现场速查版.md 和 thesis/答辩20秒口语稿.md。
2. 第二屏或后台标签页按 B、C 的顺序提前打开，不要等老师问了再找。
3. 如果老师追问某个数字来源，先报最终口径，再切到对应证据文件。
4. 如果老师追问“为什么能这样解释”，优先切 docs/thesis_experiment_report.md。
5. 如果老师追问“论文正文怎么写的”，再切 thesis/thesis_v2.md。

## E. 最容易卡住的三类问题

1. Doubao 为什么不用 98.80%。
2. Kimi 为什么不是零不一致。
3. Llama-70B 为什么教师弱但学生强。

## F. 最稳妥的统一答法

- 数字问题：以仓库内可复核 rerun 或最终 README 口径为准。
- 解释问题：先说实验现象，再说机制解释，不把解释说成直接观测。
- 外推问题：只限定在本文覆盖的标准化选择题任务范围内。
